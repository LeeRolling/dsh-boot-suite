# 第一轮「反推 bug」清单

日期：2026-10-19　范围：编辑器 / 引擎 / 宿主 / 模板 / 音频

## 一、本轮修复

| # | 现象（用户视角） | 根因 | 修复 |
|---|---|---|---|
| 1 | 换了音频/点云文件，画面和声音还是旧的 | 模板素材响应头 `Cache-Control: max-age=86400`，浏览器缓存一天 | 改为 `no-store` |
| 2 | 给音频加了机械音预设后，淡入淡出失效 | 预设走 WebAudio，音量由 gain 节点接管，但淡入淡出还在改 `audio.volume` | 淡入淡出改为作用于 gain 节点 |
| 3 | 新建音频片段默认用 line-4，模板里没有这个槽位时静默无声 | 「＋音频」写死 slot=line-4 | 改为取模板里第一个已绑定文件的槽位 |
| 4 | 槽位下拉里分不清哪个是空槽 | 下拉只显示名字 | 空槽标注「（空）」 |
| 5 | 改名成中文后被过滤成空 | 字符过滤只允许 ASCII | 允许中文（长度 ≤16） |
| 6 | 改名/删除 amb 后它又自己冒出来 | 每次渲染都补默认 amb/voice/sfx | 只在完全没有总线时补默认 |
| 7 | 音轨改名/新增找不到入口 | 名字是输入框、新增只有小按钮 | 显式「改名」按钮 + 弹窗，「＋音轨」弹窗命名 |

## 二、已修但值得记住的历史坑

| 现象 | 根因 |
|---|---|
| 坐标全部跑回 0 | 保存校验写死 96KB，大模板保存被拒 → 回落到内置旧版 |
| 编辑器显示旧版模板 | 读取时 >128KB 被静默跳过，无日志 |
| 音频不停重复播一句 | 暂停状态下主循环仍每帧触发 cue，seek 又清零标记 |
| 台词没声音 | 音频文件名含中文，引擎文件名校验只认 ASCII，静默回落占位音 |
| 终幕文字糊成一坨 | 文字采样目标 640×640 与画布 1280×720 不一致 + 步长过密 |
| 地球放大后出现巨大圆框 | 轮廓圈随半径放大；已在倍率 >1.3 时不画 |
| 字符地球放大被裁 | 画布只有 1280×720；已加自动出血 |
| 音频块点不到 | 块样式写进 splash.css，而编辑器不加载该文件 |
| 批量修改面板看不到 | 面板被插进表单视图而非时间线视图 |

## 四、建议的回归检查（每次改引擎后跑）

1. `npm test` —— 28 项契约（路由、黑屏兜底、合并契约）
2. `node tools/motion-check.mjs --template=dsh-intro --speed=2` —— 时间线是否还能跑完
3. 编辑器打开 dsh-intro → 播放 → 听音频 / 看地球 / 看标题
4. 保存 → 重开 → 确认坐标与音频 cue 都在
