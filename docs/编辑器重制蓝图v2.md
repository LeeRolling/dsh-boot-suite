## 1. 产品定位

**像剪辑软件一样剪开机动画，而不是像配置面板一样填参数。**

三条硬约束：

1. 用户无感：不懂代码、不懂曲线，也能做出好看片头
2. 直觉优先：看得见就能拖，拖了有反馈，错了能撤销
3. 不限制：轨道数、图层数、时长都不设人为上限

## 2. Resolve → 我们的设计对照

| Resolve 概念 | 我们的对应 | 采纳 |
|---|---|---|
| Project Manager | 项目管理器：每个模板 = 一个项目 | 全采纳（去 LUT/远程渲染） |
| Media Pool + Bins | 素材池 + Bin（图形预设/音频/转场/点云贴图） | 全采纳 |
| 悬停预览 | 预设缩略图悬停擦洗（离屏 320x180 缓存） | 采纳 |
| Edit Page 三栏 | 左素材池 / 中监视器 / 右检查器 / 下时间线 | 全采纳 |
| 双监视器 | 单监视器 | 不采纳 |
| V1..Vn | 图层轨（无限） | 全采纳 |
| A1..An | 音频轨（无限，轨即总线） | 全采纳 |
| 片段 clip | 片段 = 图层实例（预设拖入生成） | 改造采纳 |
| 参数级关键帧 | 每参数独立 ◆，默认线性，可改曲线 | 全采纳 |
| 关键帧面板 | 只显示有动画的参数 | 全采纳 |
| 转场 | 拖到片段交界，冻结帧混合实现 | 改造采纳 |
| 磁吸/缩放/滚动 | 同 Resolve | 全采纳 |
| 标记/章节 | Gate 交互断点 + 普通标记 | 改造采纳 |
| 字幕轨 | 不做 | 不采纳 |
| Fusion/调色/Fairlight/交付 | 不做，导出单独做 | 不采纳 |

## 4. 核心交互

### 4.1 通用

- 单击选中，Shift 多选，框选
- 拖动移动；边缘拖动 = 修剪 in/out
- Alt+拖动 = 复制
- 空格播放/暂停；J/K/L 倒放/停/正放
- 左右方向键逐帧；Shift+方向键 1 秒
- Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做
- Ctrl/Cmd+S 保存；Delete 删除；Ctrl+C/V 复制粘贴
- 吸附 N 开关；Shift+Z 适配

### 4.2 图层 = 片段

- 素材池拖入时间线 → 生成片段，落在选中轨道播放头处
- 片段有 in/out，内部承载参数关键帧
- 同轨可放多个片段（不重叠；重叠后者覆盖）
- 轨道顺序 = 叠放顺序（V1 最下）

### 4.3 检查器

- 参数分组折叠（变换/裁切/合成/音频）
- 每参数右侧：◆ 关键帧 + ↺ 重置 + 输入框 + 滑块
- 已有动画显示 ◇/◆；右键 ◆ 设缓动
- 自动关键帧开关（默认开）：改值即打帧；关闭时改基础值

### 4.4 关键帧面板

- 只显示有关键帧的参数
- 每参数一行，关键帧画在时间位置
- 可拖动、框选、批量改值、批量改缓动

### 4.5 转场

- 拖到两个片段交界处；时长可拖；参数在检查器调
- 实现：冻结前一帧 + 混合新画面
- 首批：交叉溶解 / 白闪 / 推移 / 故障

### 4.6 交互断点 Gate

- 标尺添加，拖动改时间
- 每个断点独立：按键 / 点击 / 自动（N 秒）/ 任一
- 到达暂停，恢复继续；编辑器可单独预览断点前后

### 4.7 音频

- 导入 → 素材池 → 拖到 A 轨
- 片段可修剪、调音量、淡入淡出
- 轨道头：静音/独奏/音量/波形
- 波形来自真实解码

## 5. 数据模型 schema v3

~~~
Project
  schemaVersion: 3
  id, name, fps (25|30|50|60), resolution {w,h}, durationMs
  theme, tracks: Track[], markers: Marker[]
  transitions: Transition[], assets: Asset[]
  settings: { autosaveOps, autosaveMinutes, backupMinutes, backupKeep }

Track
  id, kind: 'video'|'audio', name, index
  mute, solo, locked, visible, volume
  clips: Clip[]

Clip
  id, trackId, startMs, endMs
  kind: 'generated'|'audio'
  presetId?
  params: { [name]: ParamValue }
  keyframes: { [paramName]: Keyframe[] }
  audio?: { assetId, offsetMs, durationMs, fadeInMs, fadeOutMs, gain }

Keyframe
  t (ms), v, ease: 'linear'|'easeIn'|'easeOut'|'easeInOut'|'cubic-bezier'
  bezier?: [x1,y1,x2,y2]

Marker
  t, name, kind: 'note'|'gate'
  gate?: { resume: 'key'|'click'|'timeout'|'any', timeoutMs }

Transition
  atMs, durationMs, type: 'dissolve'|'whiteflash'|'push'|'glitch', params

Asset
  id, kind: 'audio'|'image'|'dots'|'json', bin: string[]
  file, durationMs?, size
~~~

兼容：引擎仍接收毫秒；导出视频按 fps 出帧。

## 6. v2 → v3 迁移

1. 读旧 template.json（v2 或无 schemaVersion）
2. 每个 layer → 一条 video Track 上的 Clip（in=0，out=duration）
3. 旧 keyframes[] → 拆成参数级 keyframes{}
4. 旧 audio[] → A 轨 audio Clip；bus 名变为轨名
5. 旧 segments → note markers
6. 旧 gates[] → gate markers
7. 写新项目包 + 原文件备份到 backups/
8. 失败不覆盖，列出具体图层/字段

## 7. 技术架构

~~~
packages/
  schema/     类型 + 校验 + 迁移
  core/       时间轴数学、插值、缓动、坐标（纯函数）
  renderer/   Canvas2D / WebGL2 / WebGPU + 自动探测
  editor/     WebUI（独立页面，可脱离 DSH 开发）
  host/       DSH 插件：路由、文件 IO、备份、配置
  engine/     开机播放器（复用 core + renderer）
~~~

- 编辑器与引擎共用 renderer → 真正所见即所得
- host 只暴露本地 HTTP：project CRUD、asset upload、backup
- GPU：WebGPU → WebGL2 → Canvas2D 自动降级，诊断面板显示后端

## 8. 保存 / 备份 / 恢复

| 机制 | 触发 | 说明 |
|---|---|---|
| 自动保存 | 每 N 次操作（默认 10）或每 M 分钟（默认 5） | 覆盖当前项目 |
| 版本备份 | 每 X 分钟（默认 30） | 20261019_2253_项目名_V1，保留 30 份 |
| 崩溃恢复 | 每 30 秒 | 临时文件，重启提示恢复 |
| 手动存档 | 用户操作 | 导出 .dshproj |

## 9. 测试

- 单元：schema、迁移、插值、缓动、时间轴数学
- 黄金帧：模板+时间 → 截图对比（三后端关键帧）
- 动作回放：操作日志 JSON → 重放 → 结果一致
- E2E：打开/拖拽/修剪/保存/重开
- 性能门槛：3000 粒子 < 8ms/帧，交互 60fps
- 静态检查：impeccable
