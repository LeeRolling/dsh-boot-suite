# 《代码模板规范》v0.3 增补（ORIGAMI 第三轮验证后）

> 来源：ORIGAMI（纸艺日出）。目标仍是 v1.0 前每轮把 Claude 的经验转成规范/工具。

## A. 揭示式转场（新增，硬性）

- A1. 「打开/揭示」类转场必须先露出主体，再展开覆盖物；禁止覆盖物全程盖满、到结尾才打开（我的 v1 前 4 秒白屏就是反例）。
- A2. 覆盖物要有明确运动方向与折痕/缝；观众要看得出“正在打开”。
- A3. 揭示过程中主光/主体（太阳、标题、焦点）应可见或半可见。

## B. 跨镜头常驻主角（新增）

- B1. 跨段落的视觉主角（太阳、地平线、准星）必须放在 Sequence 外常驻，不能随某段结束消失。
- B2. 分镜表必须有“跨镜头”列；换段只变状态、不重建。

## C. 分层质感（新增）

- C1. 层叠结构（山峦/剪纸/纸张）至少深 2 阶 + 1 条墨线/边缘线，否则变“灰带”。
- C2. 光扫/纸屑/飞鸟等装饰必须服务叙事节点（日出/盖章/收尾），不能全程随机撒。
- C3. 片尾四件套：标题、副标题、域名、底部署名/版权行。

## D. Validator：按命题配置能力清单（新增）

- D1. 能力关键词不能写死为 HUD；每题给一份 brief pack（elements + 检测器）。
- D2. Validator 增加“交付顺序”检查：分镜/文件块/过程日志/自检/风险 五件齐全。
- D3. 过程日志中的“动画原语选择”抽成词典，供下一轮出题与规范引用（见 E）。

## E. 动画原语词典（从 Claude 过程日志提炼）

| 原语 | 用途 | 备注 |
|---|---|---|
| clip-path 多边形 + 透视 | 折纸/揭页/山形 | 比 SVG 省节点 |
| SVG stroke-dashoffset | 墨线/轮廓生长 | 矢量不糊 |
| 种子随机 + 闭式运动 | 粒子/纸屑/飞鸟 | 可 seek |
| 混合模式 + 旋转缩放 | 印章/套印错位 | 低成本质感 |
| radial/conic-gradient | 日出/光扫/扫描 | 纯 CSS |
| 径向渐隐 | 舞台聚焦 | 控制干净 |

## F. “三个一”学习机制

每轮 Claude 交付后必须产出：1 条规范（写进增补）、1 条 validator 规则、1 条设计规则。

本轮：规范 A1；validator D1；设计 B1。
