# 《代码模板规范》v0.3 增补（ORIGAMI 第三轮验证后）

> 来源：ORIGAMI（纸艺日出）。目标仍是 v1.0 前每轮把 Claude 的经验转成规范/工具。

## A. 揭示式转场（新增，硬性）

- A1. 「打开/揭示」类转场必须先露出主体，再展开覆盖物；禁止覆盖物全程盖满、到结尾才打开（我的 v1 前 4 秒白屏就是反例）。
- A2. 覆盖物要有明确运动方向与折痕/缝；观众要看得出“正在打开”。
- A3. 揭示过程中主光/主体（太阳、标题、焦点）应可见或半可见。

## B. 跨镜头常驻主角（新增）

- B1. 跨段落的视觉主角（太阳、地平线、准星）必须放在 Sequence 外常驻，不能随某段结束消失。
- B2. 分镜表必须有“跨镜头”列；换段只变状态、不重建。

## C. 分层质感（新增）

- C1. 层叠结构（山峦/剪纸/纸张）至少深 2 阶 + 1 条墨线/边缘线，否则变“灰带”。
- C2. 光扫/纸屑/飞鸟等装饰必须服务叙事节点（日出/盖章/收尾），不能全程随机撒。
- C3. 片尾四件套：标题、副标题、域名、底部署名/版权行。

## D. Validator：按命题配置能力清单（新增）

- D1. 能力关键词不能写死为 HUD；每题给一份 brief pack（elements + 检测器）。
- D2. Validator 增加“交付顺序”检查：分镜/文件块/过程日志/自检/风险 五件齐全。
- D3. 过程日志中的“动画原语选择”抽成词典，供下一轮出题与规范引用（见 E）。

## E. 动画原语词典（从 Claude 过程日志提炼）

| 原语 | 用途 | 备注 |
|---|---|---|
| clip-path 多边形 + 透视 | 折纸/揭页/山形 | 比 SVG 省节点 |
| SVG stroke-dashoffset | 墨线/轮廓生长 | 矢量不糊 |
| 种子随机 + 闭式运动 | 粒子/纸屑/飞鸟 | 可 seek |
| 混合模式 + 旋转缩放 | 印章/套印错位 | 低成本质感 |
| radial/conic-gradient | 日出/光扫/扫描 | 纯 CSS |
| 径向渐隐 | 舞台聚焦 | 控制干净 |

## 2026-10-25 追加：ORIGAMI v3 验证后（本轮新增，只增不改）

> 来源：09-技术验证-remotion/src/origami 的 v3 重做（缝隙先露日 / 四层剪纸山峦 / 时序对齐 / 片尾四件套）
> 与 tools/validator 的 brief.json 改造。上面 A–G 保留原样，本段只补可执行细则。

### H. 揭示式转场（A 的可执行细则）

- H1. **铰链位置决定揭示方向**：想让画面「从中间向两侧」露出来，铰链必须放在画外左右边缘；把铰链放在折缝上会变成「从外向内」露。
- H2. 折门必须 **rotateY + perspective 一起用**；只写 rotateY 没有 perspective，纸会被压成平面，观众看不出在转。
- H3. 折缝里先露主体时，**缝本身要够亮**：内边加一条亮纸线 + 缝外一圈暖色漏光；否则缝和纸面同色，观众看不出已经张开。
- H4. 揭示时长 **≥1.5–2s，用 inOut**；不要用强 out 曲线（强 out 前 0.5s 就走完 80%，看起来像硬切）。

### I. 跨镜头主角（B 的工程做法）

- I1. 常驻主角组件**自己读全局帧**（useCurrentFrame），不要在 Main 里套 Sequence；它的动画区间照样写进 tokens。
- I2. 常驻主角排在覆盖物之前、内容层之后：先画主角，再画「会消失/会折走」的覆盖层。

### J. 分层质感（C 的具体配方）

- J1. 一层剪纸 = **纸底填充 + 半透明色染 + 剪口亮边（paper rim）+ 墨线**，四件齐全才有纸的厚度；只有色染会变灰带。
- J2. 亮边在墨线**之上** 1–2px，亮边用纸白、墨线用墨；顺序反了画面会脏。
- J3. 光晕一律用**径向渐变**，禁止几层同心圆半透明填充——会出现「靶环」。
- J4. 大光扫全片**只做一次**，放在结构转折点（本片：山峦升起后、活字之前），用完即走。

### K. 时间与节奏（D 的补丁）

- K1. 一条缓动不可能同时满足两种速度：需要「先快后慢」的段（如日出露头→浮出）用**两段关键帧**，不要硬调一条曲线。
- K2. 镜头开工前先写**事件节点表**：每个节点只做一件事（露缝/折开/升起/勾线/扫光/压印/盖章），节点间隔 0.4–1.2s，相邻节点不要抢戏。
- K3. 片尾四件套落位顺序：标题 → 印章 → 副标题 → 域名 → 署名；最后一笔离 hold 起点 ≥0.05s。

### L. Validator 的 brief 化（D1–D3 落地）

- L1. brief.json 是「命题包」，至少含：expect / palette / fonts / elements / delivery。
- L2. 检测器分两类：**关键词类**（regex / file，尽量跨实现通用）与**声明类**（span / before / count，读 tokens 的时间声明约定）；混在一起会把「实现命名」误判成「能力缺失」。
- L3. **画面指标也要进 brief**：redPct（朱砂占比）这类指标能把「日出必须有红色主体」变成可度量项；本次 v3 redPct=2.96%、Claude 版 2.19%。
- L4. **交付顺序检查**（delivery.order）能抓出「分镜/过程日志/自检/风险」顺序错乱。
- L5. 工具链回退写进 validator：metrics.py 在 imageio_ffmpeg 缺失时要退回 PATH 上的 ffmpeg，否则画面指标整项 FAIL。

### M. 动画原语词典补充（E）

| 原语 | 用途 | 备注 |
|---|---|---|
| 双页绕画外铰链 + perspective | 折纸/开门/揭开 | 铰链位置决定方向；>80° 后淡出收尾 |
| 径向渐变光晕 | 日出/聚光 | 替代同心圆，避免靶环 |
| 两段关键帧（快→慢） | 露头→浮出 | 一条曲线调不出来 |
| 纸底/纸染/纸白亮边/墨线四件套 | 剪纸分层 | 缺亮边就是灰带 |
| feDisplacementMap + multiply | 印章/粗糙边 | 低成本做出渗墨 |
| 指数阻尼 + 重力项的闭式纸屑 | 盖章/冲击波 | 可 seek、只服务节点 |

### O. 当前差距（v3 对比后更新）

- 客观指标（同 5fps 采样）：v3 avgY 193.1 / redPct 2.96 / inkPct 0.38；Claude avgY 186.0 / redPct 2.19 / inkPct 9.17。
  我的画面更亮更空、墨色信息更少；Claude 的深色面积更大（标题/近山/字排），视觉重量更足。
- 开场：Claude 有桌面、纸张立起、光斑多层；我的封面干净但更「平面」，第 0–1s 信息量偏低。
- 折纸：缝隙先露日是本题新增设计，但「折」只有 2.1s 且朝观众折开，观众可能读成「两片纸滑开」；下一步加折角/纸厚边，或做 3 折。
- 字排：我只有一行中文 + 一行等宽；Claude 两行英文 + 标签，排版层级更接近设计稿。
- 片尾：我的四件套 + 印章层级更清，但缺一个大面积图形收尾。
- 节奏：4.4–5.6s 有约 1s 相对静止；Claude 每 2s 内都有新状态。
