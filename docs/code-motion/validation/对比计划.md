# 对比计划（验证圣经）

## 目的

同一份命题、同一套规范，我和 Claude 各做一版；差异就是规范需要补的地方。

## 对比维度

| 维度 | 看什么 | 权重 |
|---|---|---|
| 结构 | 文件拆分、镜头划分、时间轴是否对 | 20% |
| 节奏 | 每段的停留、重叠、缓动是否顺 | 20% |
| 排版 | 对齐、留白、字号层级 | 15% |
| 质感 | 3D、光效、粒子、字体 | 25% |
| 交付 | 分镜表、ASSUMPTION、自检是否齐全 | 10% |
| 过程 | 制作日志是否讲清取舍 | 10% |

## 流程

1. 两边都渲染成 12s mp4
2. 生成 1fps 拼图 + 3 张关键帧对比（4s / 8s / 11s）
3. 按上表逐项打分，写成中文清单
4. 归纳"规范没写清 / 没约束到"的地方 → 出 v0.2 增补
5. 下一轮换一个命题再验证

## 验收

- 结构分 ≥4/5：说明规范可执行
- 交付分 ≥4/5：说明交接协议可执行
- 若质感分低：不是规范问题，是工具链问题（字体/3D/粒子库），单独排期
