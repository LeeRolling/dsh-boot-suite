# Claude 分镜表（SIGNAL，50fps，600 帧）

| 时间 | 主角 | 动作 | 缓动 |
|---|---|---|---|
| 0–1.0s | 网格 + HUD | 网格淡入并缓慢漂移，四角括号、时间码出现 | out；漂移匀速 |
| 0.3–1.1s | 十字准星 | 四臂外延，圆环描边，环外刻度出现 | out |
| 0.5–3.7s | 刻度尺 / 点线 | 刻度尺左→右展开；折线描边；6 个节点依次弹出；橙点沿线跑 | out / pop / inOut |
| 1.5–3.75s | 打字机 | 两行 mono 逐字打出，光标先常亮、后闪烁；3.4s 准星锁定，圆环收缩变橙 | 打字匀速；锁定 pop |
| 4.0–4.95s | 面板 + 准星 | 准星平移成雷达中心；3D 面板 rotateY 翻入，带一道高光扫过 | inOut / out |
| 4.7–7.9s | 进度条 + 计数 + 雷达 | 计数 0→87%，进度条同步；4.9s 起环形扫描，光点被扫到时点亮；7.6s 目标被框住 | out；扫描匀速；锁定框 pop |
| 8.25–8.62s | 计数 | 87% 切片错位，橙/灰蓝重影；8.4s 全屏闪白（≤0.3） | out |
| 8.5–10.4s | 粒子 → 标记 | 220 个粒子弧线收束到六边形轮廓；9.3s 起轮廓描边，内部三角形随后描边 | out / inOut |
| 10.1–12.0s | 片尾 | 标题 wipe 揭开；副标题、细线、域名依次淡入；最后 0.8s 静帧 | wipe / out |
