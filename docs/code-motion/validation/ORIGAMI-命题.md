# 命题：纸艺日出（ORIGAMI SUNRISE）12 秒

> 第三轮验证：换一种**完全不同的视觉语言**，检验《代码模板规范 v0.2》是否不只适用于暗色 HUD。

## 题目

做一条 12 秒的「纸艺日出」片头：暖白纸面、折纸展开、日出、剪纸山峦、墨线、活字、印章收尾。用于一个手作品牌的开场演示。

## 硬性要求

- 1280×720，50fps，12 秒（600 帧）
- 颜色 ≤4：纸白 `#F4EBDD` / 墨 `#22201C` / 朱砂 `#C8452B` / 金 `#D6A84B`
- 字体族 ≤2：衬线（标题/正文） + 等宽（小字/时间码）
- 全部图形用代码画（CSS/SVG），不联外网、不用外部图片/视频/字体文件
- 每帧可定格：禁用 CSS animation / transition、Math.random、Date.now、setTimeout、setInterval
- 随机只能用带 seed 的确定性随机

## 必须包含的元素（与暗色科技 HUD 完全不同的实现路径）

1. 纸纹背景（多层 CSS 渐变/噪点，不是纯色）
2. 折纸展开（clip-path 多边形 + 透视变换）
3. 日出圆形升起（径向渐变/圆）
4. 层叠剪纸山峦（clip-path 山形）
5. 墨线勾画（SVG stroke-dashoffset 生长）
6. 活字排版（衬线大字逐字出现） + 闪烁光标
7. 印章盖下（旋转 + 缩放 + 混合模式）
8. 纸屑/尘埃粒子（确定性随机）
9. 飞鸟路径（SVG 小 V 形，沿弧线移动）
10. 纸面光扫过（渐变扫光，一次）
11. 片尾标题 + 副标题 + 域名
12. 一次短促的“纸面错位/重影”（替代故障闪白，≤0.3s）

## 节奏

- 0.0–4.0 纸面展开、日出
- 4.0–8.4 山峦、墨线、活字
- 8.4–12.0 印章、标题、副标题、域名，片尾 hold ≥0.8s

## 交付

- tokens / parts / 每镜头一个文件 / Main
- 分镜表（必须含：退场方式、与前后镜头重叠区间）
- ASSUMPTION 逐条编号
- 自检表 + 风险/取舍说明
- **必须实际渲染过**：mp4 + 1fps 联系表 + 3 张关键帧（交付时写明路径）
