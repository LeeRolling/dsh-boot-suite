# 给 Claude 的固定交付顺序（圣经 v1.0 前每轮必加）

> 目的：每一轮都能从 Claude 的结构、取舍、自检、风险里学习，转成我们的规范与 validator 规则。

```
请严格按这个顺序交付（从这一轮起固定，直到圣经 v1.0）：

1. 分镜表：时间 / 主角 / 动作 / 缓动
2. 文件：每个文件用 === FILE: 文件名 === 开头
   （每个文件块结束再加一行 === END FILE ===，方便我拆分）
3. 过程日志：为什么这样拆分、理由是什么。每个镜头选了什么动画原语、用了什么工具，为什么用这些工具。哪些地方做了哪些取舍、为什么这么做。
   另外，不确定的地方（ASSUMPTION 列表），为什么不确定。如果只能再改一处会改哪里。
4. 自检：对照规范逐条打勾，没做到直说
5. 风险：字体 / 性能 / 确定性上最容易踩的坑

不要复刻现有作品，不要使用外部素材。

请直接开始，不要问我问题。
```
