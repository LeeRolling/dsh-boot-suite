## 1. 建议观看顺序

1. 完整看一遍正片，不暂停：第一印象是否为「纸艺日出」，12s 节奏是否成立。
2. 看左右对比片：重点比 0–1s 信息量、折纸可读性、6.9–8.2s 是否有停滞感。
3. 用并排关键帧暂停核对下面 5 条 gate 的时间点。
4. 每条给「通过 / 有条件通过 / 打回」+ 一句理由；最后填第 3 节。

## 2. 五条 gate

### Gate ① 0–1.5s：缝隙里先看到太阳

- **看什么**：0.3–1.5s 画面正中竖缝里是否出现红色，能不能被读成「太阳正在升起」；1.8s 左右折门张开后，太阳顶弧是否自然接上。
- **期望**：缝里先有红色（窄条可以接受），但最好能读出圆弧/暖光，而不是像「红色书签」。
- **我的预筛（客观）**：红色 **0.3–0.4s** 即出现（约 0.005% 面积）；**1.0s 0.20%、1.5s 0.24%、1.8s 0.58%**。1.5s 前红色始终局限在中央竖缝内（0.6s 帧红色掩膜外接框仅 32×48px@1280，见 `quant/frame-v3-seam-0.60s.png`），**读不出圆弧**；竖缝宽 0.45–1.25s 由 6px 张到 34px，1.8s 后折门张开才快速展宽。Claude 的太阳 **2.1–2.2s** 才出现（0.014%→0.71%）。→ 时序上我方早约 1.8s，可读性偏弱。
- **不对时这样反馈**：「在 X.Xs，我看到的是 ___，期望看到 ___」。

### Gate ② 3–6s：山峦与墨线有层次、不是灰带

- **看什么**：3.4–6.2s 山峦是否至少有 2–3 阶明暗层次 + 墨线勾边；光扫是否只扫一次、是否自然。
- **期望**：能看出「剪纸层叠」，墨线可见，不是只有色块。
- **我的预筛（客观）**：**层次在**——纵向梯度剖面检出 4 条画面内水平结构线（Claude 6 条），该段 stdY 33.0 vs 32.5；**但墨线极弱**：3–6s 近黑覆盖率 v3 **0.009%** vs Claude **4.279%**，最暗 1% 分位 96.7 vs 88.5 —— 我方山峦是「中灰层叠」，不是「近黑勾线」（山脊线 1.1–1.5px、透明度仅 0.36–0.62）。山峦区（下 35%）墨色占比 0.022% vs Claude 13.9%。→ 层次在、墨线弱，是本轮最大的质感差距。
- **不对时这样反馈**：「山脊线在 X.Xs 应该更明显 / 层次不够 / 光扫不自然」。

### Gate ③ 8.6–10s：印章/纸屑时序服帖

- **看什么**：标题 SUNRISE 揭开（8.6–9.3）→ 印章落下（9.05 出现、约 9.45 落定）→ 副标题淡入（9.55 起）→ 纸屑炸开（9.55 起、约 9.9 最盛）是否像一套动作。
- **期望**：盖章落定即起纸屑，不要「先盖章、过一会儿再撒纸屑」的脱节感。
- **我的预筛（客观）**：可测事件顺序——近黑覆盖率 8.6→9.0s 由 0.009% 升到 **1.165%**（标题）；红色在 **9.1s 冲峰 6.97%**（印章落下）、约 9.45s 落定；副标题 9.5–9.7s 出现；纸屑扩散峰 **9.9–10.0s（0.1s MAE 0.65）**。9.60–9.96s 有 0.36s 弱冻结（全画面均值 <0.51，局部纸屑仍在动）。→ 顺序成立；纸屑视觉上比落定晚约 0.2–0.3s，存在轻微脱节风险。
- **不对时这样反馈**：「纸屑应该更早/更晚 / 印章落下没有重量感」。

### Gate ④ 11.15–12s：四件套齐 + hold ≥0.8s

- **看什么**：① 标题 SUNRISE；② 副标题 PAPER · LIGHT · PATIENCE；③ 域名 origami.example（红色）；④ 底部署名 ORIGAMI · PAPER STUDIO · MMXXVI。四者是否都在、可读、互不打架；11.15 后画面是否真的静止。
- **期望**：四件套齐全；hold 至少 0.8s 不动（允许静态纸纹噪点）。
- **我的预筛（客观）**：四件套齐全（11.50s 静帧 `quant/frame-v3-hold-11.50s.png` 可核对）；v3 从 **10.88s** 冻结到片尾，连续 **1.12s**；11.15–12.0 整窗 **100% 冻结**（avgY 标准差 0.00，帧差 MAE 0.0015）。→ **hold 成立且有余量（1.12s ≥ 0.8s）**。
- **不对时这样反馈**：「某元素看不清 / 位置挤 / 片尾还在动」。

### Gate ⑤ 与 Claude 对比三处（v0.3 追加 O 指出的）

- **看什么**：并排对比片，重点三处：a) **0–1s 信息量**谁更空；b) **折纸是否被读成「两片纸滑开」**，还是「书打开」；c) **是否有约 1s 相对静止**。
- **期望**：三处不比 Claude 明显更空/更糊/更停滞。
- **我的预筛（客观，见 `_h1-review/quant/H-1-客观报告.md`）**：
  - a) 0–1.2s 运动能量 v3 **0.43** vs Claude **3.63**（v3 只有 Claude 的 12%，0–1s 为 0.47 vs 3.09）。我方开场更静、更亮（avgY 203.9 vs 196.2）、纸白更多（75.2% vs 49.1%），但边缘密度反而略高（封面/烫金圆标/活字），是「静但信息不缺」；是否算更空请人眼判。
  - b) 折纸可读性无量化指标；可测的只有竖缝红色宽度（0.3–1.5s 仅 8–52px@1280，1.8s 96px、2.2s 192px）。请直接看正片 0.4–3.3s 与对比片同段。
  - c) **O 段这条数据不成立**：4.4–5.6s v3 运动 MAE **2.43**（Claude 4.21）、峰值 6.91@5.1，严格档 freezedetect **0 冻结**，不是静止段；真正的长低谷在 **6.9–8.2s（v3 1.34s 近冻结；Claude 也有 1.40s）**。Claude 的硬静止在 3.2–3.9s（0.70s）。请重点看 **6.9–8.2s** 有没有「卡住」感。
- **不对时这样反馈**：「0–1s 太空 / 折纸看不懂 / 6.9–8.2s 像卡住了」。
