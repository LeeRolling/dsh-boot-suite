## 过程日志（动画原语选择，v0.3 D3）

| 镜头 | 原语 | 为什么 |
|---|---|---|
| 折纸展开 | 双页绕画外铰链 + perspective 2600 + rotateY + clip-path inset | 铰链在画外，画面从中间向两侧露出；透视让门页收窄而不是“整块滑走” |
| 折缝露日 | clip-path 缝隙 + 内边亮纸线 + 渐变漏光 | 先露主体再展开覆盖物（A1）；亮边让“纸正在折”看得见（A2） |
| 日出 | SVG 圆 + radialGradient 光晕 + clipPath 裁地平线 + 两段关键帧 | 光晕用径向渐变而不是同心圆，避免“靶环”；两段缓动同时满足“缝里快露头”和“地平线慢升” |
| 山峦 | 折线多边形 + 纸底/淡染/纸边/墨线四层 | 每层都是“纸底 + 半透明染 + 剪口亮边”，远中近 4 阶，避免“灰带”（C1） |
| 墨线 | SVG stroke-dashoffset + pathLength=1 | 矢量不糊，生长可定格 |
| 活字 | 逐字 span + scale/rotate/translate 压印 + 红光标 | 活字手感来自每字独立落点，而不是整行淡入；光标只在开始打字后出现 |
| 印章 | 关键帧 scale/rotate + multiply + feDisplacementMap | 低成本做“盖下去”的重量和渗墨 |
| 纸屑 | 种子随机 + 指数阻尼闭式解 | 可 seek；只在“打开”和“盖章”两个节点出现（C2） |
| 光扫 | 斜向 linear-gradient + screen | 一次扫过，提亮山峦暗部 |
| 片尾 | clip 揭开 + 套印错位 + 版心竖线 + 四件套 | 标题/副标题/域名/署名四个信息层级，署名压在河面上方保证可读 |

## ASSUMPTION

- ASSUMPTION #1：纸纹用 CSS 重复渐变 + 纤维曲线 + 全局 feTurbulence 近似，不引入任何图片。
- ASSUMPTION #2：双页折门采用“绕画外铰链朝观众折开”的工程近似（真纸折有多次折角），只保留一次主折。
- ASSUMPTION #3：飞鸟用两段二次曲线 + 圆点身体，不做骨骼；扇翅频率 2.5Hz 由 |sin| 驱动。
- ASSUMPTION #4：印章「日出」用 SVG 活字 + 位移滤镜做粗糙边，不做真实印泥纹理。
- ASSUMPTION #5：河与反光是装饰性剪影，不追求物理正确；反光点对齐太阳 x 以服务叙事。
- ASSUMPTION #6：字体不打包，衬线回退到系统 serif（Windows 上 CJK 走宋体），标题宽度在回退字体下仍需目视。

## 风险 / 取舍

- 字体回退：Georgia/SimSun 缺失时标题宽度变化，居左排版比居中更稳，但仍需在目标机目视。
- 3D 折门：Chrome 的 perspective 在极端角度（>80°）会出现薄片挤压，本版限制 84° 并在 2.95–3.30s 淡出规避。
- feTurbulence 全屏纹理每帧都要栅格化，渲染比纯 CSS 慢；换来纸感，取舍是渲染时间换质感。
- 山峦用折线多边形（尖角）而非曲线，远看锋利、近看略硬；这是“剪纸”语言的选择，不是遗漏。
- 片尾 hold 期间仍有极轻微纸纹噪点（静态），不是动画；联系表可对照 11.2s 与 12.0s 两帧确认。
