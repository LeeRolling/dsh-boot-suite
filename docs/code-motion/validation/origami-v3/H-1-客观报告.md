# H-1 客观量化报告 · ORIGAMI v3

> 目的：为 ORIGAMI v3 人工验收（H-1）提供可复现的客观证据，不评价画面美感。
> 输入：`out/origami-mine-v3.mp4`（我方 v3）、`out/origami-claude.mp4`（Claude）。ffprobe：均 12.000s / 1280×720 / 50fps / 600 帧。
> 工具：ffmpeg / ffprobe 9.0.2（PATH）+ 捆绑 Python 3.12.14（numpy 2.3.5 / Pillow 12.3.0）。
> 采样口径：画面指标 `metrics.py` 5fps / 60 帧；运动能量与颜色时间线 10fps（320×180，area 缩放）；冻结 `freezedetect n=0.001 与 0.002, d=0.35`；对比来源 640×360 半幅逐像素。
> 输入文件未改动；全部产出在 `out/_h1-review/quant/`。

- Claude 三个 O 段数字全部复现。v3 的 avgY、redPct 复现；**inkPct 唯一未复现**（0.49 vs 0.38）。metrics.py 对同一文件是确定性的，偏差不是抖动。**关键时间证据**：O 段所在文档 mtime 为 03:07:26，早于当前 v3 的渲染时间 03:09:10；因此 O 段 v3 数字很可能来自最终渲染前的版本（这同时解释了 avgY 0.16 的小差与 inkPct 0.11 的差）。以本次复跑的 0.49 为准。
- 方向性结论不变且更强：v3 更亮（+6.98 Y）、红色更多（2.96 vs 2.19）、近黑墨更少（0.49 vs 9.17，约 1/18.7；按 O 段 0.38 则为 1/24）、纸白更多（68.81 vs 62.54）。
- 与 `out/validator-origami-v3-report.json` 交叉核对：该报告画面明细写 `Yavg=192.93`，与本次一致；交接文档摘要表的 193.09 与明细差 0.16。以 192.93 为准。

## 二、冻结区间

`freezedetect n=0.001:d=0.35` 与 `n=0.002:d=0.35`（后者容差 2×，更容易判冻结）；片尾未闭合区间按 12.000s 收口。完整区间见 `freeze-intervals.json`、`freezedetect.md`。

| 视频 | n=0.001 | n=0.002 |
|---|---|---|
| v3 | 0.00–0.38；10.88–12.00（1.12s） | 0.00–0.40；5.44–5.80；6.90–8.24（连续 1.34s）；9.60–9.96；10.76–12.00（1.24s） |
| Claude | 3.20–3.90；10.92–12.00（1.08s） | 3.20–4.02；5.96–6.36；6.88–8.28（连续 1.40s）；10.86–12.00（1.14s） |

- **4.4–5.6s**：严格档 0 冻结；宽松档仅 5.44–5.60（0.16s）。Claude 两档都为 0。**O 段“4.4–5.6s 有约 1s 相对静止”在当前 v3 上不成立**（同期运动能量见第三节，反而高于 v3 全片均值）。
- **11.15–12.0s**：v3 与 Claude 都是整窗 0.85s 冻结（0.85/0.85）。v3 的冻结从 **10.88s** 开始、到片尾共 **1.12s**；Claude 从 10.92s 起共 1.08s。⇒ v3 的 hold 余量充足（≥0.8s 的实测值为 1.12s）。
- **8.6–10s**：v3 在宽松档有 9.60–9.96 的 0.36s 弱冻结（全画面均值 0.31–0.39，局部小元素仍动）；Claude 为 0。
- **真正的长低谷在 6.9–8.2s**：v3 连续 1.34s、Claude 连续 1.40s 落在噪声容差内。若人工验收要讨论“静止段”，位置应改到这里。

## 三、运动能量（重点 0–1.2s / 4.4–5.6s / 11.15–12s）

10fps、320×180 灰度、相邻帧 MAE（0–255）。时间线见 `motion-energy.csv`（0.2s）与 `motion-energy-0.1s.csv`（0.1s）。

| 窗口 | v3 | Claude | 说明 |
|---|---|---|---|
| 0–1.0s | **0.467** | **3.089** | v3 为 Claude 的 15% |
| 0–1.2s | **0.432** | **3.629** | v3 为 Claude 的 12% |
| 1–2s | 1.491 | 2.042 | 折纸展开段 |
| 3–6s | 1.585 | 1.983 | 同量级 |
| **4.4–5.6s** | **2.427** | **4.208** | v3 为其全片均值的 2.38 倍 |
| └ 窗内最安静 0.4s | 1.597 @4.7–5.1 | 2.312 @5.2–5.6 | v3 为自身全片均值的 1.57 倍 |
| 8.6–10s | 1.164 | 0.747 | v3 印章段更动 |
| **11.15–12s** | **0.0015** | **0.0005** | 完全静止 |
| 全片 | 1.020 | 1.257 | 尺度参照 |
| 全片峰值 | 6.906 @5.1 | 10.297 @5.1 | 两片最大动作都在 5.1s 附近 |

- **0–1.2s**：v3 0.43、Claude 3.63，Claude 是 v3 的 8.4 倍；0–1s 为 0.47 vs 3.09（6.6 倍）。配合颜色时间线（0–1.5s：avgY 203.94 vs 196.18，paperPct 75.17 vs 49.13），**“开场更亮、更空、变化更少”有像素依据**。
- **4.4–5.6s**：v3 不静止——该窗均值 2.43，为自身全片均值的 2.38 倍，5.1–5.2 出现全片最大 MAE 6.91；最安静 0.4s 也只有 1.60。Claude 同窗 4.21，二者都在 5.0–5.3 有一次大动作。**O 段的“约 1s 相对静止”在该渲染上测不到。**
- **11.15–12s**：v3 0.0015（全片均值的 0.15%）、Claude 0.0005，且与 freezedetect 的 10.88/10.92 起冻结一致。**v3 的片尾是真正的像素级 hold。**
- **排除片尾后最安静窗口**：v3 0.148 @7.7–8.1；Claude 0.0215 @3.5–3.9（对应其 3.2–3.9 冻结）。v3 在片尾前没有第二个硬冻结，只有 6.9–8.2 的低谷。

## 四、compare-v3 来源结论

对比片 `out/origami-compare-v3.mp4`（1280×360 = 两个 640×360 半幅）。t=1.0 / 6.0 抽帧，半幅与源视频同时刻帧比较（详见 `compare-provenance.md`）：

| 时间 | 假设 A：左=v3 右=Claude | 假设 B：左=Claude 右=v3 | 剔除标签后 A |
|---|---|---|---|
| 1.0s | **MAE 2.85 / PSNR 26.8 dB** | MAE 22.85 / PSNR 19.3 dB | MAE 1.52 |
| 6.0s | **MAE 2.96 / PSNR 25.8 dB** | MAE 23.04 / PSNR 16.6 dB | MAE 1.48 |

- **结论：现有 compare-v3 是假设 A——左=v3、右=Claude。** A 的 MAE 只有 B 的约 1/8，PSNR 高 7.5–9.2 dB；剔除标签区后 A 降到 1.5（只剩缩放/重编码差），B 仍在 22–24。两个时间点结论一致。
- **时间对齐**：A 假设下 t±0.1 / ±0.02 偏移都会抬高 MAE（1.0s 的 Claude 半幅：0.9s→6.02、1.0s→2.88、1.1s→12.50；6.0s 两侧均在 6.0 取最小），**同时间轴、误差 ≤0.02s（1 帧）**，没有整段错位。
- **文字标签**：两半左上角各有一个白字标签（640×360 半幅坐标下白字外接框约 80×15 px；对应源帧该处近白像素为 0），只在左上角，没有全幅遮罩；两半交界处无分隔线（列均值变化来自两侧内容本身）。比较细节时应避开左上角。

## 五、五条 gate 的客观佐证

**① 0–1.5s 缝隙先看到太阳**：红色像素在 **0.3s** 首次出现（0.005%，320×180 下仅 2×3 px），**1.0s 0.20%、1.5s 0.24%、1.8s 0.58%**；0–1.5s 红色均值 0.129%。红色区域在 1.5s 前始终局限在画面中央的竖缝内（宽 2–13 px@320，即 8–52 px@1280；0.6s 帧红色掩膜外接框为 32×48 px@1280，见 `frame-v3-seam-0.60s.png`）。Claude 的红色 **2.1s** 才出现（0.014%），2.2s 达 0.71%。⇒ **“红色（太阳）先于其他内容出现”在时序上成立**；但 1.5s 前红色面积 ≤0.25%，“是否已被看成太阳”仍属人眼判断。

**② 3–6s 山峦/墨线有层次**：同一 10fps 管线内，v3 该段 stdY 33.0（Claude 32.5）、edge 4.33（4.66），纵向梯度剖面（代理指标：0.25×峰值为阈值、间隔 ≥12 行）检出 **4 条画面内水平结构线**（y≈73/119/131/156 @180p，另有页眉 1 条；Claude 6 条）⇒ **明暗层叠结构在**。但近黑 inkPct 仅 **0.009%**（Claude 4.279%），最暗 1% 分位 96.7（Claude 88.5）——该段的“墨线”落在 95 阈值之上，是**中灰层叠，不是近黑勾线**。⇒ 支持“有层次”，不能支持“墨线深/可读”。

**③ 8.6–10s 印章/纸屑时序**：可测事件顺序为——近黑覆盖率从 8.6s 的 0.009% 升到 9.0s 的 1.165%（标题出现）、9.1s 红色峰 **6.97%**（印章）、9.5–9.7s 副标题出现、9.9–10.0s 纸屑扩散（0.1s MAE 0.65）；9.60–9.96 有 0.36s 弱冻结（全画面均值 <0.51，局部纸屑仍在动）。金色覆盖率在 8.6–10s 仅 0.07–0.10%（Claude 0.67–0.76%，但主要来自光环而非纸屑），**单色掩膜无法定量纸屑数量**。⇒ 可量化的是“标题→印章→副标→纸屑”的先后与 0.1–0.3s 间隔；“服帖”与否仍需人眼。

**④ 11.15–12s 四件套齐且 hold≥0.8s**：v3 从 **10.88s** 冻结到片尾（**1.12s**），11.15–12.0 的 0.85s 整窗 100% 冻结；该段每 0.1s 的 avgY / redPct / inkPct / paperPct 完全相同（avgY 标准差 0.00，red 4.418%，ink 1.17%，paper 61.44%）。11.50s 静帧可核对到标题 / 副标题 / 域名 / 底部署名四组文字（`frame-v3-hold-11.50s.png`）；validator 的“片尾四件套”源码项通过，为源级旁证，不是画面证据。⇒ **hold = 1.12s ≥ 0.8s，成立且有余量**；四件套“齐”由静帧核对。

**⑤ 与 Claude 对比三处**：(a) 0–1.2s 运动 **0.43 vs 3.63**（0–1s：0.47 vs 3.09），开场 v3 明显更静、更亮（avgY 203.9 vs 196.2）、纸白更多（75.2% vs 49.1%）——支持 O 段“0–1s 信息量偏低”；(b) 折纸可读性**没有客观指标**，可测的只有缝隙红色宽度：0.3–1.5s 仅 2–13 px@320，1.8s 24 px、2.2s 48 px，即“窄缝先露红条、1.8s 后才快速张开”；(c) **4.4–5.6s 不是静止段**：v3 2.43 vs Claude 4.21，v3 峰值 6.91@5.1；真正的低谷是 6.9–8.2s（v3 1.34s 近冻结），Claude 的硬静止在 3.2–3.9s（0.70s）。⇒ **O 段第三条需要修正**。

**数据不能替答**：①“红条是否被读成太阳”、②“灰阶山峦是否算有质感”、③“纸屑时序是否服帖”、④“四件套排版是否成立”、⑤“折纸是否被读成两片纸滑开”——这些是观感/语义判断，本报告只给时序、面积、亮度、运动量、冻结区间。
