- 视频：09-技术验证-remotion/out/signal-v1.mp4（12s / 1280×720 / 50fps / 349KB）
- 代码：09-技术验证-remotion/src/signal/

## 已知不足

- 3D 面板翻入完成后仍是平视，缺受光/投影细节
- 粒子只有 90 个，收束感一般
- 字体依赖系统 Inter，未内置
- 闪白一帧过强，截图上整帧发灰（实际只有 6 帧）
- 没有写 ASSUMPTION（我自己的规范自己没遵守，这正是验证要暴露的）
