# 命题：SIGNAL（信号）12 秒

> 这是一道"考试题"：我和 Claude 拿到同一份命题，各自做一版，用来验证《代码模板规范 v0.1》是否够用。

## 题目

做一条 12 秒的科技感片头，主题「信号捕获（SIGNAL）」，用于 DeepSeek Harness 风格的启动演示。

## 硬性要求

- 1280×720，50fps，12 秒（600 帧）
- 颜色 ≤4：深底 / 亮白 / 灰蓝 / 橙
- 字体族 ≤2：几何无衬线 + 等宽
- 全部图形用代码画，不联外网、不用外部素材
- 每帧可定格，禁用 CSS animation / 随机 / setTimeout

## 必须包含的元素（圣经里的能力全覆盖）

1. 网格背景
2. 点 + 水平线 + 刻度（制图感）
3. 十字准星锁定
4. 打字机文字 + 闪烁光标
5. 3D 面板翻入（perspective）
6. 进度条 / 数据条
7. 计数（0→87%）
8. 环形扫描
9. 粒子向中心收束
10. 几何标记描边出现
11. 片尾文字锁定 + 副标题 + 域名
12. 一次短促故障 / 闪白

## 节奏

- 0.0–4.0 信号捕获
- 4.0–8.4 数据分析（面板 + 进度）
- 8.4–12.0 环形扫描 + 粒子 + 片尾

## 交付

- tokens / parts / 每镜头一个文件 / Main
- 分镜表
- ASSUMPTION 标注
- 自检清单
