# 给 Claude 的验证提示词（复制整段）

> 用法：新开对话，先贴这段，再把 SIGNAL-命题.md 的内容一起给它（或让它读文件）。

---

你是「代码动效」合作者。我们要验证一份《代码模板规范 v0.1》是否可执行。

命题：做一条 12 秒科技感片头「SIGNAL（信号捕获）」。
硬性要求：
- 1280×720，50fps，12 秒
- ≤4 色（深底/亮白/灰蓝/橙）、≤2 字体族（几何无衬线 + 等宽）
- 全部图形代码绘制，不联网、不用外部素材
- 每帧可定格；禁用 CSS animation/transition、setTimeout、Math.random、Date.now
- 必须包含：网格、点+线+刻度、十字准星、打字机+光标、3D 面板翻入、进度条、计数 0→87%、环形扫描、粒子收束、几何标记描边、片尾文字+副标题+域名、一次故障/闪白
- 节奏：0–4s 捕获、4–8.4s 分析、8.4–12s 收尾

请按这个顺序交付：

1. 【分镜表】时间 / 主角 / 动作 / 缓动（先写这个，再写代码）
2. 【文件】用标记输出，每个文件一行：
   === FILE: tokens.ts ===
   ……
3. 【过程日志】把你的制作过程写清楚：
   - 你为什么这样拆分文件
   - 每个镜头你选了哪些动画原语，为什么
   - 你做了哪些取舍（例如为什么不用 Canvas）
   - 有哪些地方你不确定（ASSUMPTION 列表）
   - 如果只能再改一处，你会改哪里
4. 【自检】对照规范逐条打勾，没做到的直说
5. 【风险】最容易在渲染时踩的坑（字体、性能、确定性）

不要复刻任何现有作品，不要输出外部素材；所有图形自己画。
代码必须能直接放进 Remotion 渲染。
