# 给 Claude 的验证提示词（用户修订版 · 明天发这版）

> 说明：不告诉 Claude 这是"验证规范"，让它按真实工作方式产出，过程日志才自然。

---

命题：做一条 12 秒科技感片头「SIGNAL（信号捕获）」。

硬性要求：
- 1280×720，50fps，12 秒
- ≤4 色（深底/亮白/灰蓝/橙）、≤2 字体族（几何无衬线 + 等宽）
- 全部图形代码绘制，不联网、不用外部素材
- 每帧可定格；禁用 CSS animation/transition、setTimeout、Math.random、Date.now
- 必须包含：网格、点+线+刻度、十字准星、打字机+光标、3D 面板翻入、进度条、计数 0→87%、环形扫描、粒子收束、几何标记描边、片尾文字+副标题+域名、一次故障/闪白
- 节奏：0–4s 捕获、4–8.4s 分析、8.4–12s 收尾

请按这个顺序交付：

1. 分镜表：时间 / 主角 / 动作 / 缓动
2. 文件：每个文件用 === FILE: 文件名 === 开头
3. 过程日志：
   - 为什么这样拆分
   - 每个镜头选了什么动画原语、用了什么工具，为什么要用这些工具
   - 做了哪些取舍、为什么这么做
   - 不确定的地方（ASSUMPTION 列表），为什么不确定
   - 如果只能再改一处，会改哪里
4. 自检：对照规范逐条打勾，没做到直说
5. 风险：字体/性能/确定性上最容易踩的坑

不要复刻现有作品，不要使用外部素材。
