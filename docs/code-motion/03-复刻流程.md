# 复刻流程（固定流水线）

## 第 1 步：拿到参考

- 能下载 mp4 就下载；下不到就录屏
- 记录：时长、帧率、分辨率、来源链接、作者

## 第 2 步：拆时间线（机器做）

- 1fps 拼图：整条时间线一眼看完
- 10fps 拼图：每 2.5 秒一张，5×5
- 找到画面突变点，切成镜头，给每段起中文名（如 S5 故障换字）

## 第 3 步：给 AI 的分帧包（机器做）

- 总览：10fps 拼图 6 张
- 细节：对难点段做 20fps + 1:1 裁切
- 说明：第 k 格 = 起始秒 + 0.1×k（10fps）

## 第 4 步：AI 写代码（AI 做）

- 先读 01 规范
- 先交分镜表，再交文件
- 按 02 交接协议输出

## 第 5 步：接进来（机器做）

- 按标记拆分 → 清理 → 写入 → 编译 → 修错

## 第 6 步：渲染（机器做）

- 固定帧率渲染成 mp4
- 记录渲染耗时和文件大小

## 第 7 步：对比（机器做）

- 同时间点左右并排
- 自动拼对比图：整片 1fps + 难点 10fps
- 把差异写成中文清单（亮度/大小/位置/节奏/字体/质感）

## 第 8 步：回喂（人 + AI）

- 用户只判断"像不像"，不用看代码
- 每次只改差异最大的 1–2 段，最多 3 轮
- 每轮把对比图 + 中文修改清单丢回给 AI

## 验收标准

- 结构、节奏、排版：必须对上
- 质感：允许有差距，但差距要能说清楚是哪几项
- 每次交付都留下：代码、视频、对比图、差异清单
