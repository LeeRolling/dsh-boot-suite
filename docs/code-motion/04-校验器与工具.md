# 校验器与工具（说人话版）

## 校验器是什么

像机场安检：模板写完后，机器自动检查一遍，
不合格就打回，不让它进插件、不让用户看到黑屏。

检查项：

- 时长/帧率/分辨率对不对
- 有没有偷偷联网、引外部图片
- 有没有用"随机"导致每次播不一样
- 颜色/字体是不是超了预算
- 有没有可能卡顿的大特效
- 时间写没写死、镜头有没有空洞
- 交付格式对不对（分镜表、ASSUMPTION、文件标记）

## 交接协议是什么

像快递单：AI 交付时按固定格式贴标签（每个文件一行标记），
我这边按标签自动拆包，不靠人手复制，不会漏行。

## 要做的工具（按顺序）

1. 拆包器：txt → 文件（按 === FILE: 标记）
2. 规范检查：上面那几条自动打分
3. 渲染器：一条命令出 mp4
4. 分帧器：mp4 → 1fps/10fps 拼图
5. 对比器：两个 mp4 → 左右并排 + 差异拼图

先用"我手动做一遍"，把步骤记录下来，再固化成脚本。
