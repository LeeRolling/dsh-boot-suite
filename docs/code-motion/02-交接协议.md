# AI 交接协议（不用人手复制代码）

## 问题

用户看不懂代码，手动复制容易漏行、粘进说明文字（已经发生过）。

## 协议

AI 输出代码时，每个文件用一行标记开头：

    === FILE: tokens.ts ===
    （文件内容）
    === FILE: Shot_Intro.tsx ===
    （文件内容）

用户只做一件事：把 AI 的整段回复**原样粘进一个 txt**，保存到桌面，告诉我路径。

## 我这边怎么做

1. 按 === FILE: 标记自动拆分文件
2. 自动清理文末的说明段落（不是代码的部分）
3. 写入项目目录
4. 编译；报错就修
5. 渲染；出对比帧
6. 把"哪里不一样"用中文告诉用户，不贴代码

## 为什么能抗上下文丢失

拆分靠标记、不靠记忆；规则在文件里、不靠对话。新窗口只要读到这页，就能继续。
