# 代码模板制作规范 v0.1（草案）

> 这是"圣经"的第一版，后续只增补、不推翻。所有 AI 写模板前必须先读这份。

## 1. 一个模板由什么组成

    tokens       风格常量：颜色、字体、缓动
    parts        可复用零件：X 标记、火焰、光晕、文字样式
    shots        每个镜头一个文件，只负责自己的时间段
    main         把 shots 按时间摆好

原则：**先定风格，再做零件，最后拼镜头。** 不允许一个文件写完整片。

## 2. 硬约束（违反直接打回）

- 1280×720 或 1920×1080；25/30/50/60fps；时长 3–30 秒
- 颜色 ≤4 个主色；字体族 ≤2
- 所有动画都是"第 f 帧"的纯函数（可定格、可重渲染）
- 禁止：CSS animation/transition、requestAnimationFrame、setTimeout、Math.random、Date.now
- 禁止联网、外部字体/图片/视频；图形用代码画
- 禁止复刻他人素材/品牌资产；只学结构、节奏、排版
- 随机必须用固定种子；故障/抖动按帧阶梯更新

## 3. 性能预算

- 同屏动画元素 ≤80；Canvas 粒子 ≤3000；SVG 节点 ≤500
- blur 半径 ≤40px，同屏带 blur 层 ≤3；禁止全屏 backdrop-filter
- 不逐帧动画 box-shadow / width / height / top / left（用 transform/opacity）

## 4. 交付格式（给 AI 的）

- 先给分镜表：时间 / 主角 / 动作 / 缓动
- 再给文件：tokens、parts、shots、main
- 不确定处标 ASSUMPTION
- 最后给"需要核对的几处"清单
- 不写长篇解释

## 5. 自检（AI 交付前自己过一遍）

- 总帧数 = 时长 × fps，Sequence 无空洞
- 时间用秒 → 帧换算，不写死帧号
- 每个镜头一个主角，同屏动作 ≤3
- 文字落定后停留 ≥0.8 秒
- 首帧、末帧、每镜头首末帧都能定格检查
- 字体依赖写清楚（缺字体时回退什么）
