# 坐标系约定（待执行的重构方案）

> 状态：**方案已定，代码未迁移**。当前仓库保持 d0e6558 的可用状态。
> 原因：三类特殊图层各写了一套定位，半改状态比不改更危险；需要一次专门、可逐步验证的迁移。

## 现状（三种写法并存）

| 图层 | 现在的定位方式 | 问题 |
| --- | --- | --- |
| text / line / logo | 基类 absolute（left/top auto）+ `translate(-50%,-50%) translate(x,y)` | 隐式依赖"static position = 0,0" |
| globe | `left:pos; top:pos; margin:-size/2` | 与基类约定不同 |
| chars | `left:0; top:0` + `translate(x-w/2, y-h/2)` | 只支持固定尺寸 |
| idcard | 同 chars | offset/scale 关键帧没生效 |

## 目标约定

**left/top 恒为 0；位置只由 transform 表达；元素中心 = (cx, cy)。**

```js
function placeLayer(node, cx, cy, w, h, extra) {
  node.style.left = '0px'
  node.style.top = '0px'
  node.style.transform =
    'translate(' + (cx - w / 2) + 'px,' + (cy - h / 2) + 'px)' + (extra || '')
}
```

每帧由 applyTimeline 统一刷新：

```js
placeLayer(node, baseX + ox, baseY + oy, w, h, ' scale(' + sc + ') rotate(' + rot + 'deg)')
```

## 迁移步骤（每步都要跑定位测试模板）

1. 新建 `templates/pos-test`：四角 + 中心各放 text / chars / idcard 三类，画面上标注坐标
2. 先迁 text/line/logo（它们已符合约定，只补显式 left/top:0）
3. 再迁 globe：build 里登记 `gsize`，apply 里用 placeLayer(cx,cy,gsize,gsize)
4. 再迁 chars：节点固定 1280×720，画布坐标系 = 舞台坐标系，球心固定在 (640,360)；
   pos/offset 只影响节点 transform
5. 再迁 idcard：build 登记 cardW/cardH，apply 里支持 offset/scale 关键帧
6. 每迁一个，截图四角定位模板 + 550C 复刻 4.2s/15s，确认无偏移
7. 全绿后，再改终幕：`buildTextTargets` 用 1280×720、字号 0.26H、采样 7px
