## 长版

**DeepSeek Harness 开机动画 · 开源**

给 DeepSeek Harness 加一段六幕冷启动动画：黑幕 DeepSeek 标识 → 过曝洗白 →
暖白「技术档案」底板 → 五步交互式访问授权 → 色散故障揭幕 → 落进聊天。

不是视频，是**代码动画**：画面部分只有 94 KB 的 JS + CSS，随窗口大小任意清晰；
台词是真声音频，界面音效现场合成；33 项都能在设置页里改（身份名称、编号、权限等级、
配色、速度、音色、语速、每一处文案）。

进聊天之后还能接上自己的东西：开场视频、聊天底图、铺满窗口的大字横幅。
底图丢进目录就自动换，视频支持循环区间（剪辑软件时间码直接填）。

**它之前在哪儿**
这个插件原来是两个独立的插件：`dsh-startup-screen`（开机动画）和
`dsh-chat-wallpaper`（聊天壁纸）。装两个、配两份、坏一个查半天，
现在合并成 `dsh-boot-suite` 一个包，配置文件名没变，老设置直接继承。

**怎么装（Windows 桌面端）**
1. 完全退出 DeepSeek Harness Desktop（任务管理器里确认没有进程）
2. 下载本仓库（Code → Download ZIP，或 git clone）
3. 双击根目录的 **安装.cmd**
4. 重新打开桌面端

命令行党也可以：
```
dsh plugin --profile desktop add link:<仓库路径>
```

**出问题了怎么办**
- 界面黑屏 / 点不动：任务管理器结束全部 DeepSeek Harness 进程 → 双击 **卸载.cmd** → 重开，界面就回来了
- 想退回旧版本：`tools\rollback.cmd`（需要先用 `tools\make-backup.ps1` 留过备份）
- 想知道卡在哪：看 `~/.dsh/boot-suite-diag.log`
