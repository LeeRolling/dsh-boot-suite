## 2. 样本里反复出现的「不丑、不错位」规律

这些是人工审核样片背后的硬约束，比审美灵感更可复用：

1. **风格 = 一组强约束参数**，不是感觉词。
   样本里成篇出现的固定项：画布 1920×1080、固定色板（3–6 个十六进制色）、固定线条宽度/线帽、固定纸张纹理颗粒、固定字体族与字号级差。换风格本质是换这组参数。
2. **运动都有「入场—停留—退场」结构**，且有明确时长预算。
   典型写法：单镜 0.8–2.5s；转场 0.15–0.5s；镜头缓慢推近（1.02→1.06，持续 8–12s）；禁频闪、禁随机跳变。
3. **版式是数字约束**：安全边距、对齐网格、标题字号 ≥ 画面高 6–8%、正文与背景对比度阈值、元素永不贴边。样本会直接写「不要贴边」「文字不超出 92% 安全区」。
4. **实现范式统一**：单文件 HTML + Canvas/SVG + 纯函数 `render(t)`；确定性随机（mulberry32 之类）；时间归一化到 0–1；**禁 Math.random / 禁 setTimeout**；15–30s 后在浏览器可播、可录屏。这与我们之前 MV 失败复盘的教训（禁不确定动画、禁自由代码）完全同向。
5. **细节清单化**：示例 B6 的提示词把「12 秒一镜到底、相机 z 轴 0→3100、5 环粒子 4000、标题落点、颜色十六进制、明确 Do/Don't、自检清单」全部写死——所谓「不错位」= 把位置/时间写成数字，而不是留给模型发挥。
