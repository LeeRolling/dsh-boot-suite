## 2. 模板结构与关键字段

```
schemaVersion / id / name / duration / theme{mode:'dark',bg:'#000',bg2:'#000',accent:'#d6d0c8'}
segments:[{name:'连接中',from:0,to:9200},{name:'加载中',from:9200,to:25920}]
texts:{username, tips:[{title,l1,l2}×5]}
layers:[ …41 层… ]
```

- 坐标：`pos:[x,y]` 为 **1280×720 舞台坐标**，默认居中锚点；所有环形/面板层用 `logo`（custom paths）以本地 `720×720` viewBox 绘制，`logoSize:720`，圆心本地 `(360,360)`。
- 环心：外层 HUD 组 `(640,368)`，内圈亮环/进度 `(640,350)`（参考视频各环并不同心，取折中值）；百分比 `counter` 层 pos 为 `(640,358)`（参考实测字高 20px ≈ 27–28px 字体，引擎锁定 34px Consolas，用全程 `keyframes.scale = 0.86` 补偿）。
- tips 面板：参考**没有完整边框**，只有两道暗发丝横线（y=154 / y=198，x 404→875）+ 左右两枚亮短竖线（x=397.5 / x=881.5，y 170→183）；已用 `tips-hair` / `tips-side` 两个 logo 描边层按实测复刻，不再使用 panel 边框。
- 动画全部走 `keyframes:[{t,opacity,offsetX,offsetY,scale,rotate,value,draw,typed,wipe}]`；`draw`(logo 描边生长)/`typed`(打字)/`wipe`(擦除)/`value`(counter/progress)/`rotate`。
- 本模板只用到 4 种图层：`logo`（环形、刻度、tips 框线/图标/页码方块/头部白刻度）、`text`（连接中/加载中/tips 文字）、`counter`（百分比）、`panel`（全屏闪白、编号辉光、收尾黑幕）。
- 关键层 id：`connect-user`（用户名文本）、`p-arc`（进度弧，draw 0→1）、`p-head`（进度头部白刻度，rotate=百分比×3.6）、`pct`（百分比 counter）、`tips-title/tips-body1/tips-body2`、`fx-flash`、`fx-fadeout`。

## 3. 可编辑参数

1. **用户名**：`texts.username`（当前 `人类与AI的日常`）。
   - ⚠️ **引擎不会自动替换**：2.14.0 的 splash.js 里没有 username→text 层的替换逻辑（只有欢迎语/工牌用到 identity）。
   - 需要插件侧在 **build/prepare 阶段**把 `layers` 中 `id === 'connect-user'` 的 `text` 字段替换为 `连接中：<username>`（原文为 `连接中：人类与AI的日常`）。
2. **进度**：编辑 `p-arc.draw`（0→1）、`p-head.rotate`（=百分比×3.6°）、`pct.value`（0→100）三处关键帧即可，三者同源（`gen.py` 里的 `CURVE`）。
   当前曲线（ms:百分比）：9500:0 / 10000:0 / 10500:10 / 12000:29 / 13000:41 / 14000:43 / 20000:43 / 21000:46 / 22000:51 / 23000:55 / 24000:59 / 25000:63 / 25500:100 / 25920:100。
3. **tips 文案**：`texts.tips`（5 组）。当前画面固定显示第 1 组（参考视频 25.92s 内 tips 不翻页）；换文案时同步改 `tips-title/tips-body1/tips-body2` 三层的 `text`。
4. 进度弧没有用 `progress` 层，而是 `logo` 描边 + `draw`：为了 1:1 复刻宽度/端头形状（progress 层是矩形条，且 CSS 自带蓝光 box-shadow）。

## 4. 字体说明

- 文本/标题/正文：`--dsu-din` = `Bahnschrift, DIN Alternate, DIN Condensed, Archivo, Oswald, Arial Narrow, … Microsoft YaHei, PingFang SC, sans-serif`
  → Windows 上拉丁字符落到 **Bahnschrift**、中文落到 **微软雅黑**；标题 17.5px / 正文 11px / 连接中 20px / 加载中 18px 均为对齐参考后的补偿字号。
- 百分比：引擎固定 `600 34px/1 Consolas, Menlo, monospace`（**字体与字号不可改**），颜色取 `theme.accent`（设为 `#cbc7c1` 灰白）。参考实测字高 20px、字宽 ≈14.75px/字符（≈27–28px 的窄体数字），本模板用 counter 层全程 `scale: 0.86` 使渲染字高 = 20px；Consolas 字宽仍偏宽（"63%" 实测 50px vs 参考 44px）。
- 参考视频的标题/正文字体是横向压缩的 DIN 风格，本机无该字体，字号已补偿但字宽无法 1:1 → 见已知差异第 1 条。

## 6. 已知差异（按重要性）

1. **字体无法 1:1**：参考标题/正文是横向压缩 DIN，Windows 回退中文为微软雅黑 → 字面更宽、更粗；百分比引擎锁定 34px Consolas，参考为 ≈27–28px 窄体数字（已用 `scale 0.86` 对齐字高，字宽 Consolas 仍偏宽，无法改）。
2. **环几何与光学**：参考各环不同心（外层≈(640,368)、亮环≈(640,349)），亮环近似椭圆（顶部 r≈72.5 / 底部 r≈53.5 / 左右 r≈61），并带 bloom 光晕与轻微色噪声/暗部渐晕；本模板用正圆 + 单色描边 + 一个 `panel` box-shadow 辉光近似，整体比参考更亮、更"干净"。参考的亮弧沿角度还有内外偏移（近似螺旋），本模板为同心圆弧。
3. **tips 多色高亮 + 转场**：参考正文首个短语为橙色高亮（单 text 层做不到单层多色）；翻页的"碎裂→横向切片扫描→逐字归位"（见 `refs-4k/字体转场A-规格.md`）引擎没有对应 effect，本模板只用 `wipe` 近似淡入。若要 1:1 需插件侧给 text 层加 `effect.decode`。
4. **切场与 boot**：9.2–9.6 参考为逐字碎裂 + 白闪；本模板用轻微全屏白闪（峰值 opacity 0.18）+ 图层 opacity 切换近似。boot 0.3s 时本模板仍有极淡的 HUD 轮廓（参考只有亮环）。
5. **小图标/页码方块**：tips 左侧背包图标、「下一则」键盘图标为描边近似；页码方块（8×5px）用 logo 短线 + 圆头端点近似（panel 层有 20px 最小尺寸限制，无法画小方块）。
6. 进度在 11.0s 附近本模板 ≈17%，参考 ≈10%（lead 提供的曲线 + harness 383ms 偏移共同造成，10.0/12.0/14.0/20.0/25.0/25.5s 均对齐）。
