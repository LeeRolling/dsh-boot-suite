# 出图要求：描线动画用素材

> 目标：让人物"被线条一条条描出来"，再扫描显影。
> 上一张（厚涂无描线）不行，原因：内部没有线，边缘检测只能捡到明暗噪声。

## 一、最优方案：给两张图（强烈推荐）

| 图 | 内容 | 要求 |
|---|---|---|
| **线稿图** | 只有线，没有填色 | 黑线 + 纯白底，或白线 + 纯黑底；线闭合、粗细一致 |
| **完成图** | 同一角色的彩色成稿 | 与线稿**同尺寸、同构图、同位置**（叠上去严丝合缝） |

为什么最优：我直接把线稿矢量化，不做边缘猜测，线条质量等于参考片。
两张对齐后，动画就是「线稿逐条生长 → 完成图渐显」，中间不需要任何抠图。

## 二、次优：一张带描线的成稿

要求：**赛璐璐（cel-shading）画法 + 明确深色轮廓线**。

- 轮廓线要真正的线（深色、连续），不是靠明暗对比"暗示"出来的边
- 线宽在 1024 画布下约 2–4 px
- 平涂上色，**不要**大面积渐变/厚涂/水彩晕染
- 高光用色块，不要用光晕（发光边缘会被当成噪声）

## 三、通用硬要求（两种方案都适用）

| 项 | 要求 |
|---|---|
| 尺寸 | 正方形 1:1，**≥1024×1024**（2048 更好） |
| 背景 | **透明 PNG 最好**；不行就纯白或纯黑，不要渐变、不要场景 |
| 构图 | 单主体、居中、**占画面 70–85%**，四周留白 ≥5%，**不许裁到画布边缘** |
| 元素 | 只要角色本体。**不要**文字、星星、爱心、贴纸、水印、道具特效 |
| 光照 | 不要强逆光、不要辉光、不要镜头光斑、不要动感模糊 |
| 发丝 | 可以有，但**不要**几十根极细碎发（会断成几千个小段） |
| 格式 | PNG（不要 JPG，压缩噪点会变成假线条） |

## 四、禁止清单（踩中任一条就得重出）

- 厚涂 / 半厚涂 / 水彩 / 写实渲染
- 画面里带背景场景、天空、光晕、粒子
- 主体小于画面 50%，或贴着/超出画布边
- 多角色 / 半身特写裁到脸
- 线条是"画出来的渐变边"（软边、毛边、发光边）

## 五、可直接用的出图提示词（英文，给 AI 绘图用）

**线稿（第一张）：**

    clean anime line art, single character portrait, full clean outlines,
    consistent line weight, closed contours, black lines on pure white background,
    centered composition, no shading, no colors, no background elements,
    no glow, no text, square 1:1, high resolution

**完成图（第二张，与线稿同构图）：**

    same character, same pose, same framing as the line art,
    cel-shaded flat colors, clean dark outlines, no gradients on skin,
    pure white or transparent background, no props, no sparkles, no text,
    square 1:1, high resolution

## 六、我拿到之后跑什么（验收标准）

1. 线稿二值化 → 骨架化 → 断点连接 → Douglas-Peucker 简化
2. 统计：**连续线条数 ≥ 150 条、单条平均长度 ≥ 40px**（512 宽下）
3. 生成 `trace.json`（路径 + 时序），体积控制在 **100 KB 以内**
4. 出一版 demo（描线 + 扫描显影），给你看效果再决定进不进引擎

如果第 2 步不达标（线条太碎/太少），我会直接告诉你哪一条不满足，而不是硬做。
