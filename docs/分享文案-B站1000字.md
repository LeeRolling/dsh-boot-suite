DeepSeek Harness 开机动画 · 开源

给 DSH 加一段六幕冷启动动画：黑幕 DeepSeek 标识 → 过曝洗白 → 暖白「技术档案」底板 → 五步交互式访问授权 → 色散故障揭幕 → 落进聊天。

不是视频，是代码动画：画面只有 94 KB 的 JS+CSS，任意分辨率都清晰；台词是真声，音效现场合成；33 项都能在设置页改。进聊天后还能接上自己的开场视频、聊天底图、大字横幅。

它原来是两个插件（dsh-startup-screen + dsh-chat-wallpaper），装两个、配两份、坏一个查半天。现在合并成一个包，配置文件不变，老设置直接继承。

【怎么装 · Windows 桌面端】
① 完全退出 DeepSeek Harness Desktop（任务管理器确认没有 DeepSeek Harness 进程）
② 下载仓库（Code → Download ZIP）并解压
③ 双击根目录的「安装.cmd」
④ 重新打开桌面端

装过旧版也不用管，安装.cmd 会自动卸掉那两个旧插件。

【出问题怎么办】
界面黑屏或点不动：任务管理器结束全部 DeepSeek Harness 进程 → 双击根目录的「卸载.cmd」→ 重开桌面端，界面就回来了。
