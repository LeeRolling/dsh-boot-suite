## 4. 新模板行为（iframe 触发 / 跳过 / 彩蛋 / 结束信号）

**基本信息**：`id=division-bigfish-codex`、`engine=iframe`、`entry=index.html`、`duration=25.92s`。

- **触发**：宿主 `splash.js` 读到 `TEMPLATE.engine === 'iframe'` → `runIframeTemplate`，全屏 iframe 加载
  `/dsh-startup/template-file/division-bigfish-codex/index.html`（勾选强制彩蛋时追加 `?egg=1`）。
- **播放**：模板自行走时间轴 —— 连接态 0–9.2s → 加载进度 9.2–25.92s → 100% → 白闪 → 结束。
- **跳过**：模板内生成 `#skip`「跳过▸」；点击或 Esc → `dispatchEvent(new CustomEvent('dsh-startup-skip'))` + `parent.postMessage({type:'dsh-startup-skip'})` + `__DSH_SKIP__()`；宿主收到任一路径即 `finishOnce()`。
- **彩蛋**：`EGG_CHANCE = 0.28`；进入加载段时掷一次随机（`?egg=1` 强制命中）；命中即**硬切**到掉线画面：
  雪地底图 + 黑纱 + 「《战术大肥鱼®》服务目前无法使用，请点击重试按钮。」+ `DELTA / C-0-1302` + 「重新连接」+ 底部 DSH。
  播 line4 语音，2s 后自动 `reconnect()`：重播 9.2→25.92 进度段。每次启动最多一次。
- **结束**：`flashDone()` 白闪 260ms → `doneEmit()`：DOM 事件 `dsh-startup-done`、`parent.postMessage({type:'dsh-startup-done'})`、`__DSH_DONE__()` 三路同时发；宿主 `finishOnce()`。
- **兜底**：宿主对加载失败/超时另有兜底收尾（不黑屏）；模板在 `t >= duration` 时若语音未播完，最多等 3500ms 再 flashDone。
- **调试接口**：`window.__DSH_APP__ = {play, pause, seek, showEgg, eggFrame, flashDone}`。
