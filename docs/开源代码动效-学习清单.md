## C. 蒸馏方法（合法且高效）

1. **先读结构，不读细节**：`SKILL.md` 怎么写、`src/` 怎么分镜、渲染脚本怎么调
2. **提炼规范**：把它们的“节奏规则/能力白名单/性能预算”抄成我们的《模板编写规范》
3. **重写不复制**：同一效果用我们自己的组件实现，保留自己的代码风格与许可
4. **许可红线**：MIT/Apache 可学可参考（需署名）；AGPL 只学思路，不复制代码；Remotion 公司使用需看其许可

## D. 下一步（建议）

1. clone `lemo-opuscar` 与 `Jacky-motion`，各写一份“结构拆解”（不贴大段代码）
2. 从里面提炼 `SPEC.md` 草稿（能力白名单、时间写法、自检清单）
3. 用 Remotion 把我们自己的 S5 重写成符合规范的组件
4. 跑通“改一个参数 → 重新渲染 → 对比”的循环
