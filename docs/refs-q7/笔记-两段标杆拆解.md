## V1 拆解（ZAFT 启动序列）

时间线：
- 0–2s：徽标从暗处浮现，光带斜扫，星点/光晕
- 2–4s：徽标+白字全称「Zodiac Alliance of Freedom Treaty」，一次闪光爆点
- 4–9s：启动窗——顶部白霓虹大写「MOBILE SUIT OPERATION NEO SYSTEM」；紫色半透明窗口（黄进度条 + 打字机式 G.U.N.D.A.M 缩写逐行展开 → Complex）；左侧竖排编号「ZGMF-X20A」；底部「Z·A·F·T」；四角黄字警告（PILOT CERTIFICATION NOT COMPLETED / WILL BE PROCESSED. PLEASE WAIT）；窗口内徽标淡显水印
- 9–13s：换面板——「GUNDAM Complex」大字头 + 缩写小块 + SYSTEM UPDATED 打字 + LAUNCH 按钮（绿色播放图标） + 进度条
- 13–18s：回到徽标全屏，光晕收尾（闭环）

分层（可直接映射 template.json 的 layers）：
1. 背景层：深蓝渐变 + 斜光带 + 星点（缓慢漂移）
2. 徽标层：红翼形 + 青色斜十字 + 白色椭圆环；带发光/闪白
3. 顶标题层：白色压缩大写 + 外发光
4. 状态窗层：半透明紫面板 + 内细边框 + 黄进度条 + 打字文本 + 缩写列
5. 侧标层：竖排青色编号
6. 角标层：四角黄色微文本
7. 底标层：Z·A·F·T 带横线
8. 结束/交互层：SYSTEM UPDATED、LAUNCH 按钮
字体观感：类 Bank Gothic / Orbitron 的压缩大写 + 等宽打字小字。

## V2 拆解（全境封锁加载界面）

时间线：
- 0–1s：近黑场 + 细网格/战术地图线 + 顶部真实调试代码（Serial.println("Publish message") 等，UI 课作业彩蛋）
- 1–8s：橙色双环进度 0%→98%（圆环+刻度+中心大号百分比+环上跑马灯+发光）
- 8–11s：白色鹰徽从环内出现 + 「ANONYMOUS『THE DIVISION 2』」+ 「CONNECTED TO THE NETWORK OF BUREAU OF 999999999」

分层：
1. 背景层：近黑 + 细网格 + 战术线条（微动/呼吸）
2. 进度环层：双环 + 刻度 + 中心数值 + 光晕
3. 角标层：橙色小字/日志
4. 徽标层：白色鹰徽（从环内浮出）
5. 字幕层：等宽小字，逐条出现

## 共性骨架（可模板化的部分）

5 段式：**Logo 出现 → 系统名/标语 → 状态/进度 → 完成/启动 → 收回 Logo（闭环）**
90s 军事科幻 HUD 视觉词汇：压缩大写字体、霓虹发光、扫描线、半透明面板、细边框、刻度环、角标微文本、竖排编号。
动效语言：光扫、闪白、打字、环进度、刻度旋转、音效点（whoosh / beep / typing）。
时长：参考 11–18s；做 DSH 开机版建议 3–8s（每段 1–2s，节奏压缩）。

## 映射到 WovenFrame 模板（v1 可行性）

- 现有 `template.json` 的 layers / keyframes / segments 可表达 90%：背景、徽标、标题、状态窗、进度条、角标、字幕都能落。
- 需要新增的参数族（每模板 4–8 个，符合 L1 参数面板设计）：
  1. 主标题（默认 DeepSeek Harness）
  2. 副标题/全称
  3. 状态条目列表（3–6 条，可编辑文案）
  4. 进度时长/是否显示数值
  5. 主色 / 强调色
  6. 徽标选择（内置几何 / 上传 PNG）
  7. 音效开关
  8. 节奏档（标准 / 快）
- 需要补的原语（若现有模板引擎不够）：打字机文本逐字 reveal、环形进度（Canvas arc 或 conic-gradient）、扫描线/噪点（CSS 重复渐变，低成本）、刻度环旋转、发光文字（text-shadow / -webkit-text-stroke）。
- 字体：打包 OFL 字体 Orbitron + Share Tech Mono（约 200–400KB），避免系统字体回退。

## 难点 / 风险

- 适配：16:9 与 9:16 各一套锚点 + 安全区；4K 下微文本别糊。
- 「信息轰炸」感来自高密度小字：模板化时必须把微文本默认成占位文案（用户可改），否则换品牌就穿帮。
- 版权：只学骨架/氛围，不搬徽标/角色/商标。
- 时长：开机动画场景要短；建议模板默认 6s，参数可拉到 15s。
