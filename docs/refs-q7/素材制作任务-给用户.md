
## 任务 4：三个"短音效"是什么（不是台词）

不是配音，是**界面音效**（无台词、纯电子声）：

| 文件 | 是什么 | 时长 |
|---|---|---|
| `sfx-beep.mp3` | 按钮/提示"嘀"一声 | 80ms |
| `sfx-scan.mp3` | 扫描时的"滋——" | 400ms |
| `sfx-lock.mp3` | 锁定/确认的"咔哒" | 200ms |

MiniMax 若能出音效就给我；不能的话我用 WebAudio 现场合成，零成本，不阻塞。

## 任务 5：两件"听不懂"的事（白话版）

### 5.1 实机录屏
模板做好后，你在**自己电脑上**打开 DSH、让它真实启动一次，同时用录屏软件把屏幕录下来（Windows 自带 Xbox Game Bar：Win+G；或 OBS）。
要求：60fps、1080p 以上、录 2–3 次取最顺的一次。
用途：①商店预览视频（真实感）；②验收证据（证明真机能跑）。

### 5.2 装包测试
我把做好的模板打成一个 `.dshpkg` 压缩包发给你；
你在 DSH 的插件设置里点"安装模板"，选这个包 → 看能不能装上、启动动画对不对。
装不上 / 显示不对，就把报错截图发我。这是**最有用的验收**（我这边模拟不了你的真实环境）。
