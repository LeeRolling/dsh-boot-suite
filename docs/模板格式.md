# 模板格式（v2.2.0 已实现）

> 引擎侧已落地：选中的模板由宿主读成纯 JSON，经 `__DSH_STARTUP_TEMPLATE__` 下发；
> 运行时**只读数据、不执行代码**。分幕数量 **1~24 任意**，不写 `steps` 就用引擎内置的五幕。
>
> 位置：插件自带 `templates/<id>/template.json`，或 `~/.dsh/startup-templates/<id>/template.json`。
> 选择：配置项 `template`（`~/.dsh/dsh-startup.json`），留空 = 内置。
>
> 当前内置：`archive-warm`（= 原来的六幕，原样保下来当基准）。

> 目标：**模板 = 纯数据**。任何人做一个模板，就是一个文件夹、一个 json、一张预览图。
> 不执行任何代码，所以可以放心从陌生人那里拉取。

## 一、目录结构

    templates/<模板 id>/
      template.json      # 唯一必需的清单
      preview.gif        # 必须：动图预览（商店列表优先显示）
      preview.png        # 建议：静帧（GIF 加载前的占位、缩略图兜底）
      assets/            # 可选：模板自带的图/音（没有就全走内置）
      LICENCE.txt        # 建议：素材来源与授权说明

### 字段说明（只列关键的）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 小写字母数字加连字符，全局唯一 |
| `name` / `author` | ✅ | 商店列表里显示的名字与**原作者**。基于别人作品改编时，`author` 写原视觉/文案作者，`adaptedBy` 写改版者——**不要把别人的作品署成自己的** |
| `adaptedBy` | 选填 | 改色、改编、重排的人（如 `"LeeRolling"`） |
| `assets` | 选填 | 模板自带的配音槽位 → 文件名映射，例如 `{ "line-1": "assets/line-1.mp3" }`。会用 `/dsh-startup/template-asset/<id>/<文件>` 下发；没配就回落到全局 `lib/assets/line-N.mp3` |
| `license` | ✅ | 模板本身的许可（素材来源写在 LICENCE.txt） |
| `preview.gif` | ✅ | **必须**：动图预览，商店第一眼看到的就是它 |
| `preview.png` | 建议 | 静帧，GIF 加载失败时兜底 |
| `theme` | ✅ | 颜色与字体，全部是 CSS 变量的值 |
| `shape` | 可选 | 那个「环」的形状；可以是任意 SVG 路径 |
| `steps` | ✅ | 六幕（或任意幕）：文案、音频槽、按钮、停留时长 |
| `duration` | 建议 | 用于商店里标注"约多久" |

### 硬约束

1. **只有数据，没有代码**。不允许 `eval`、不允许内联 JS、不允许外链脚本。
2. **缺什么都能跑**：引用的图/音缺失时回落到内置默认，绝不能黑屏。
3. **体积**：`preview.gif ≤ 5 MB`，`assets/` 合计 ≤ 10 MB。
4. **音频槽**只能引用内置的 `line-1..6` / `sfx-*`，或自带 mp3（≤ 1 MB/条）。

## 三、商店怎么工作（不建服务器）

没有后台，全靠 GitHub：

    dsh-boot-suite-templates/            ← 单独的仓库，只放模板
      index.json                         ← 商店列表（唯一的"数据库"）
      templates/archive-warm/
      templates/cold-terminal/
      ...

`index.json`：

```json
{
  "schemaVersion": 1,
  "templates": [
    { "id": "archive-warm", "path": "templates/archive-warm", "author": "LeeRolling" },
    { "id": "cold-terminal", "path": "templates/cold-terminal", "author": "xxx" }
  ]
}
```

客户端拉取方式（以后实现）：`https://raw.githubusercontent.com/LeeRolling/dsh-boot-suite-templates/main/index.json`
然后按 `path` 取各自的 `template.json` 和 `preview.gif`。

**投稿方式**：给模板仓库提 PR（加一个文件夹 + 在 index.json 加一行）。
**不想进官方索引**也可以：自己开仓库，提交时把 URL 发到 issue，我们按需加进 index。
