# 官方下载与“中毒”误报说明

## 只从官方渠道下载

- GitHub Releases：https://github.com/LeeRolling/dsh-boot-suite/releases
- npm：https://www.npmjs.com/package/dsh-boot-suite
- 源码：https://github.com/LeeRolling/dsh-boot-suite

不要从第三方 fork、网盘转载、“整合包”或短视频评论区链接下载。仓库有 13 个 fork，其中个别 fork 会自行打 Release；它们不是官方构建，无法保证内容与官方一致。

## 已知的杀毒软件误报

Windows Defender 可能把更新器的命令行报成：

```
Trojan:Win32/FileFix.BBA!MTB
```

这是对 PowerShell `-EncodedCommand` 启动方式的启发式误报，检测的是命令行，不是安装包文件；插件包 SHA-256 不变。项目交接文档里已记录该问题，安全做法是解压官方包后双击 `tools\install.ps1` 或 `安装.cmd`，不要使用“生成脚本再执行”的第三方启动器。

官方发布包内没有 `.exe` / `.dll`，只有 JS、PowerShell、CMD 脚本和媒体资源；运行时只从 GitHub Release 下载更新并校验 SHA-256。

## 如果你真的遇到报毒

请提供以下信息，便于判断是误报还是被替换：

1. 杀毒软件名称与完整检测名；
2. 检测到的文件完整路径；
3. 该文件的 SHA-256；
4. 下载来源（官方 Release / 网盘 / 群文件 / 第三方 fork）；
5. 截图或检测日志。

如果哈希与上面的官方值不一致，说明文件已被替换，请立即删除并从官方 Release 重新下载。
