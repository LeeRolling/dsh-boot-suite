## 背景

我在做一个「用代码生成动效视频」的工具（类似 Remotion 的路线），想学习两种公开参考片的实现原理：

1. **SuperX feature release teaser**（15s，Product UI 分类）

   - 观感：黑底、红色光晕、X 标识变形、等式排版、故障换字、UI 卡片、粒子爆开、片尾
2. **Claude motion design showreel**（15s，Kinetic type 分类）
   - 参考页：https://motionvideo.xyz/category/kinetic-type/videos/ayushunleashed-ece3e3

已知线索：该站点自称 “Motion design, written in code”“rendered from a prompt”，
其 skills 页面列出了 Remotion 等栈。我猜是 AI agent 写 React/CSS/SVG/WebGL 代码后渲染成 MP4。

## 我要的产出（请按这个结构回答）

### 第一轮：总体架构

1. 这类 15 秒代码动效片，你会选什么栈？Remotion / 纯 React+CSS / Canvas / WebGL / Three.js / 其它？理由和取舍。
2. 时间轴与编排怎么组织：每个镜头一个组件？用 frame 驱动还是 CSS animation？如何保证逐帧确定性？
3. 缓动与节奏：一般用哪些 easing 曲线？“停留/重叠/先后”的经验规则是什么？
4. 渲染输出：Remotion 渲染 MP4 的典型配置（fps、码率、分辨率）与常见坑。

### 第三轮：关键能力专项

1. **故障字**：RGB 分离用三层文字 + mix-blend-mode: screen 可行吗？切片抖动用 clip-path 还是 SVG feDisplacementMap？如何避免“假”和糊？
2. **三维卡片翻面**：CSS `perspective + rotateX/Y` 与 Three.js 的取舍；投影/受光怎么模拟？
3. **点阵球**：球面均匀分布（Fibonacci sphere）怎么算？投影、深度排序、深度透明度怎么做？Canvas 还是 WebGL？
4. **粒子与光晕**：Canvas 2D 粒子 vs WebGL instancing；bloom 用 CSS filter 还是后处理？
5. **字体**：这类片常用哪些开源几何无衬线（Inter / Space Grotesk / Archivo / 其它）？可变字体逐字动画注意什么？
6. **时间码/等宽 HUD**：等宽字体选择、字幕对齐、扫描线/噪点怎么做不廉价？
