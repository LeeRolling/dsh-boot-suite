# 引擎 v2 · 动效物理参数备忘

> 来源：`feitangyuan/motion-web` 的"物理阻尼"思路（CC BY-NC，只学思路不搬代码）
> + `pbakaus/impeccable` 的动效命令设计。
> 目的：把"感觉"换成可填的参数，让同一种手感能被复现、被微调、被测试。

## 一、为什么不用手调 easing

CSS 的 `cubic-bezier` 描述的是**时间 → 位置**的曲线，一次写死。
物理参数描述的是**力**：刚度、阻尼、质量。好处是：

- 同一组参数在**任意时长/任意距离**下都成立（不会"短动画太飘、长动画太黏"）
- 可以自然产生**过冲与回弹**（弹簧感），手写 bezier 要试很多次
- 可被**自动测试**（见 `tools/motion-check.mjs`）

## 二、弹簧参数（单自由度，质量归一）

    加速度 a = -k·x - c·v          k = 刚度 stiffness，c = 阻尼 damping
    固有角频率 ω₀ = √k
    阻尼比 ζ = c / (2√k)

| ζ | 行为 | 什么时候用 |
|---|---|---|
| ζ < 1（欠阻尼） | 会过冲、回弹几下才停 | 弹性元素、按钮、面板弹出 |
| ζ = 1（临界阻尼） | 最快且**不过冲** | 位移、镜头推进、进度条 |
| ζ > 1（过阻尼） | 慢、拖沓 | 大质量物件、缓慢就位 |

推荐档位（m = 1，时长按"收敛到 99%"算）：

| 用途 | stiffness | damping | ζ | 收敛 |
|---|---|---|---|---|
| 快速反应（按钮/高亮） | 260 | 16 | 0.50 | ~0.35 s，轻过冲 |
| 标准过渡（面板/文字进场） | 180 | 24 | 0.89 | ~0.55 s，几乎不过冲 |
| 沉稳就位（镜头/大块） | 110 | 21 | 1.00 | ~0.85 s，无过冲 |
| 完全静止（读数/数字滚动） | 300 | 35 | 1.01 | ~0.3 s，不弹 |

## 三、错峰（stagger）与节奏

- 同族元素依次入场：**每项间隔 40–80 ms**；元素越多间隔越小
- "先结构后细节"：大块（0–300ms）→ 中等（200–600ms）→ 细节（500–900ms）
- **不要**所有元素同一时刻开始：那看起来像"整体淡入"，没有层次
- 一个屏幕里的**主动效**不超过 2 个（第三个性感的东西会互相抢）

## 四、我们怎么用

模板字段（策划中）：

```json
"motion": {
  "spring": { "stiffness": 180, "damping": 24, "mass": 1 },
  "stagger": 60,
  "stepGap": 120
}
```

运行时做法：用弹簧参数**预计算**每个元素的位移曲线（或近似成 cubic-bezier，`cubic-bezier(0.2, 0.9, 0.2, 1)` 一类的族），
再套到现有的 `ms()` 时间轴上——不引入运行时物理引擎，首帧成本不变。

## 五、怎么用自然语言准确描述动效（给非程序员的模板）

不要说"高级感""呼吸感""有灵魂"。换成这八格：

| 格子 | 问什么 | 例子 |
|---|---|---|
| **1 对象** | 动的是什么 | 标题行 / 鲸鱼标识 / 身份卡 / 整屏 |
| **2 变化量** | 从哪到哪（可量） | 透明度 0→1；位置 +28px；缩放 0.94→1 |
| **3 时长** | 多久完成 | 320ms |
| **4 曲线** | 加速还是减速 | 先快后慢 / 先慢后快 / 匀速 / 带一点回弹 |
| **5 时机** | 什么时候开始 | 上一句英文打完 120ms 后 |
| **6 顺序** | 谁先谁后 | 分隔线先，主标题后 80ms，英文再后 60ms |
| **7 停止** | 到哪算完 | 稳稳停住 / 停住后抖一下 |
| **8 声音** | 配什么声 | 无 / 哒一声 / 低频铺底 |

**模糊 → 精确 的对照：**

| 模糊 | 精确 |
|---|---|
| "要有呼吸感" | "每 2.4 秒上下浮动 4px，缓入缓出，不要回弹" |
| "高级一点" | "去掉所有 200ms 以下的动效，只保留 2 处主动效" |
| "有点弹性" | "弹簧 k=260 c=16（ζ≈0.5），过冲 2 次后停" |
| "快一点" | "总时长从 620ms 降到 420ms，曲线不变" |
| "氛围感" | "底噪 −62dBFS 全程不断；扫描线 opacity 0.55；色差 1px" |

**最省事的一句话格式**（我收到就能直接改）：

> 「改【对象】，【指标】从 A 到 B，用时 C，曲线 D，紧跟在 E 之后」

例：「改主标题，透明度 0→1、位置 +24px，用时 380ms，先快后慢，紧跟在分隔线画出后 100ms」
