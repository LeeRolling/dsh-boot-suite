# 分镜规格 · DeepSeek Harness 开机片头（v1）

> 来源：用户 2026-10-19 口述。本文是**可执行规格**：每一幕的时间轴、元素、参数、状态。
> 参考图：UEG 首页（地球在中、logo+中英标题+按钮）、UEG 身份卡三栏（终端码流 / 用户框 / 地球+进度）。
> 配色：主 #1E48BA、副 #72A2EA、中性 #F4F8FF、底 #04070D。

## 总结构

| 幕 | 时长 | 内容 | 交互 |
| --- | --- | --- | --- |
| 第一幕 | 约 8s | 漂浮字符 → 鲸鱼线描 → 标题 → 载入条 → 按钮 → 粒子成地球 | 第一幕末**等用户点击**「申请访问许可」 |
| 第二幕 | 7–9s | 地球移到右侧；左侧终端码流；中间用户登录框；数值 0→100 | 自动 |
| 第三幕 | 约 8s | 地球回中间、描边消失、粒子散开成 WELCOME BACK → 闪 → 欢迎回来 → 闪 | 自动，结束回桌面 |

| 时间 | 元素 | 状态/参数 |

| 0.0s | 背景 | 纯黑 #04070D |

| 3.0–3.4s | DeepSeek（英文） | 字号约 20，在中文下方，字距放大 |
| 3.6–6.2s | 【正在载入中】 | 小字，位于标题下方 |
| 3.6–6.2s | **进度条** | 0→100%，2.6s；条宽约 420，高 2px |

## 第二幕（约 8s）

排版三分栏（参考图 2）：左=终端码流，中=用户登录框，右=地球+进度。

### 右栏
| 时间 | 元素 | 状态 |
| --- | --- | --- |
| 0.0–1.2s | 地球 | 从上方（x 640,y 180）匀速移到右侧（x≈1120,y 260），直径约 300 |
| 0.4–8s | 【正在检查登录环境】 | 地球下方小字 |
| 0.6–8s | **跳动的数值** | 0→100%，数字跳动（每 50–120ms 变一次，非匀速），等左侧进度到位后 2s 才到 100% |
| 7.0–8.0s | 数值到 100% | 停在 100% |

### 中栏：用户登录框（重点）
| 元素 | 说明 |
| --- | --- |
| 左上角 | DEEPSEEK USER LOGIN |
| 头像 | **用户上传 + 裁切**（编辑器里选图、拖拽裁切框） |
| 二维码 | **假二维码**（随机方块矩阵，不可扫） |
| 波形 | 音频波形（用户稍后给真实波形素材；先做占位） |
| 扫描线 | 0–100 期间自上而下扫描，**不穿出框**；扫到哪一行，该行文字高亮，线走后恢复 |
| 右下角 | ISSUED BY LOGIN USER · VERIFIED BY DEEPSEEK |
| 台词 | 7 秒英文旁白（检查/确认类），示例见下 |

### 左栏：终端码流
| 元素 | 说明 |
| --- | --- |
| 内容 | 假代码无限滚动，不停 |
| 底部进度条 | 0→100%，**先到 100%**；到后码流停止 |
| 结束后 | 显示【身份比对完成 - 授权等级（3）】 |
| 等级字符 | 支持 1 位数字 / 1 个英文字母 / 1 个汉字（例如"屌"也行） |

**时序约定**
1. 左栏进度 0→100（约 5s）→ 停在 100
2. 2s 后，右栏数值到 100
3. 左栏 100% 时，码流停止，出【身份比对完成 - 授权等级（X）】

## 第三幕（约 8s）

| 时间 | 元素 | 状态 |
| --- | --- | --- |
| 0.0–2.0s | 地球 | 从右侧**匀速**回到画面中心（x→640） |
| 0.0–2.0s | 地球**描边/底光** | 同步淡出（outline 1→0），粒子保留 |
| 2.2–6.2s | 粒子散开成字 | form 0→1，WELCOME BACK，全屏宽 86% |
| 6.2–8.2s | 停住 2s | 文字静止 |
| 8.2s | 整体闪一下 | 全画面白闪 ~80ms |
| 8.3s | 变成「欢迎回来」 | 粒子重组成中文四字（字数少，需要第二套落点） |
| 10.3s | 再闪一下（转场） | 白闪 ~100ms |
| 10.5s | 结束 | 交还 DSH 桌面 |

> 注：用户口述里"两段文字"的顺序是 WELCOME BACK → 欢迎回来，最后闪回桌面。
