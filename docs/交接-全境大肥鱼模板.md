## 3. 插件补丁改了什么（搜 `DIVISION OVERLAY` 定位）

部署副本 `pkg/lib/splash.js` 内新增（仓库源码未改）、且**只对 `TEMPLATE.id` 以 `division` 开头的模板生效**：

1. `divisionOverlayInit(stage)`：在 `buildTimeline()` 里创建一块 1280×720 的 canvas 叠在视频层上（逻辑坐标，`fitStage` 自动 letterbox）；同时隐藏内置 `.dsu-skip`（避免与自绘「跳过」重复）。
2. `divisionOverlayDraw(t)`：主循环 `loop()` 里每帧调用（在 `applyTimeline(tl, elapsed)` 之后）。`t < DIV_CONNECT_MS(9200)` 画用户名；否则画当前 tip。
3. 空格翻页：`divOverlayInit` 里注册 window capture keydown；`t >= DIV_CONNECT_MS(9200)` 时按空格 → `idx = (idx+1) % tips.length`，并记录 `transAt = t`（触发字体转场 A，`DIV_TRANS_MS = 600`）。
4. `divisionMakeSkip(stage)`：自绘「跳过 ▸」（右上角，逻辑坐标 1262,24），点击调用 `requestSkip()`；失败时派发 Escape 兜底。
5. 连接态用户名、面板文字坐标、字号、颜色全部集中在两处：`divisionDrawUsername()` 与 `divisionDrawTip()`。

## 4. 数据流

```
template.json.texts.username  →  连接态「连接中：{username}」
template.json.texts.tips[]    →  加载态当前 tip（title / l1 / l2）
空格（仅 t>=9200）             →  idx+1 → 方块高亮跟随 → 600ms 字体转场 A
点击「跳过 ▸」                →  requestSkip() → 直接进入桌面
```

方块：5 个，`x = 809 + i*11, y = 212, w = 7, h = 4`；当前项 `#ff7500`，其余灰。

## 5. 常用维护动作

- **改 tips 文案**：只改 `template.json` 的 `texts.tips`（两处副本都要同步），无需动 JS。
- **改标题/正文位置字号**：`splash.js` 里 `divisionDrawTip()`（标题 412,151 / 21px；正文 397,172 与 397,187 / 12.5px；下一则 415,219 / 10px）。
- **改翻页转场时长**：`DIV_TRANS_MS`（默认 600）。
- **改连接态文字**：`divisionDrawUsername()`（中心 642,556 / 20px）。
- **换视频底片**：替换两处 `assets/bg.mp4`（保持 1920×1080、纯黑底、时长同步改 `template.json.duration`）。
- **回滚插件**：`Copy-Item "$pkg\lib\splash.js.bak-division-overlay-20261031-170916" "$pkg\lib\splash.js"`，重启 DSH；并删除 `~/.dsh/startup-templates/division-bigfish`（仓库里的模板副本可留作存档）。
- **语法自检**：`node --check "<pkg>\lib\splash.js"`（已通过，当前 182,959B）。

## 6. 已知限制 / 注意

- 视频层在引擎里默认静音；BGM 由插件侧接入（模板内不放音频）。
- 编辑器「预览」页会强制隐藏 `.dsu-skip`（host-startup.js 预览注入），所以预览里看不到「跳过」，正式启动才有。
- 叠层文字字体用系统「微软雅黑 / Segoe UI」；若之后要换不侵权字体，只需改 `divFont()`。
- 时间轴按视频 25.92s 全片；若要剪到 15–17s：先重导 `bg.mp4`，再把 `template.json.duration` 改成对应毫秒，`DIV_CONNECT_MS` 同步调整。
- 启动动画是视频模板：编辑器里不可逐元素编辑；可编辑的逐元素版本在 `docs/proto/shd-boot/v08c/`（代码动画线，仍在磨 99%）。
