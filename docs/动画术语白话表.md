# 动画术语白话表（随用随补）

> 用途：用户不是程序员，沟通时把“我想要的效果”翻译成制作术语；每次遇到新词补一行。
> 约定：左边是**术语**（做动画的人/AI 一看就懂），中间是**白话**，右边是**我们项目里在哪用到**。

## 一、线条/绘制类

| 术语 | 白话 | 项目里用到 |
|---|---|---|
| **描边生长 / 线描动画** | 像拿笔沿着轮廓一笔一笔把图形“画”出来，而不是整张图淡入 | 插件第一幕描 DeepSeek LOGO；本模板 v0.7 的徽标与战术鱼 |
| **stroke-dashoffset 动画** | 描边生长在网页里的实现名字：先量出路径多长，再用“虚线偏移”把它一点点露出来 | `lib/splash.js` buildLineArt |
| **Trim Paths（修剪路径）** | AE 里做描边生长的功能名，和上面是同一件事 | 参考：插件第一幕 |
| **Vector / 矢量** | 用“数学路径”画的图，放大不糊；PNG 是“像素图”，放大就糊 | 我们的 logo-line 是 PNG，需矢量化后才能描边生长 |
| **Vectorize / 矢量化** | 把像素图转成矢量路径的过程（我这次会用“骨架化+折线追踪”） | v0.7 的 `assets/line-paths.js` |
| **笔尖 / Pen tip** | 描边生长时“当前笔走到哪里”的光点 | v0.7 计划：发光小点跟着路径走 |

## 二、画面层次/叠加

| 术语 | 白话 | 项目里用到 |
|---|---|---|
| **图层（Layer）** | 像一叠透明胶片，每层放不同东西，上面的盖住下面的 | 面板/徽标/字幕/鱼各一层 |
| **遮罩（Mask）** | 用一块形状“挡住”或“露出”另一层的一部分 | 旧版用螺旋遮罩冒充描线（v0.7 要替换） |
| **纱（Veil / Overlay）** | 半透明的暗色/雾面盖在画面上，让底下的内容“退后” | 结尾鱼暗化成纱、Matrix 雨在纱下 |
| **透明度（Alpha / Opacity）** | 0=全透明，1=完全不透明 | 呼吸、淡入淡出、鱼暗化 |
| **合成（Composite）** | 把多层按顺序叠成最终画面 | 每一帧都是一次合成 |

## 三、时间/运动

| 术语 | 白话 | 项目里用到 |
|---|---|---|
| **关键帧（Keyframe）** | 在时间轴上标“第几秒是什么样”，中间自动补 | 插件模板 template.json 的 keyframes |
| **缓动（Ease）** | 让运动“起步慢→中间快→停下慢”，不机械 | easeOutCubic、inOutCubic |
| **帧率（fps）** | 每秒多少张画面；30fps=每秒30帧 | 本模板 30fps；用户要求最终模板 60fps |
| **时长（Duration）** | 动画总长 | 16.0s（480 帧） |
| **时间轴（Timeline）** | 横向排时间、纵向排图层的编辑界面 | 剪映式编辑器主视图 |

## 四、镜头/效果

| 术语 | 白话 | 项目里用到 |
|---|---|---|
| **声呐扫描（Sonar sweep）** | 一圈光从中心向外扩，像雷达扫描 | 开场、鱼出场 |
| **故障/毛刺（Glitch）** | 画面短暂错位、切片、抖动，像信号不稳 | 徽标旋转时、WELCOME 出字时 |
| **透视面片（3D quad / wireframe）** | 像 3D 建模软件里那种“透视四边形网格” | 开场 3D 面片 |
| **Matrix 雨（Digital rain）** | 黑客帝国那种竖排随机字符往下掉 | 第三幕背景（纱下暗层） |
| **闪黑（Cut to black）** | 画面快速压黑，用于收尾/转场 | 15.25s 收尾 |
| **角标（Corner mark / Badge）** | 固定在角落的小徽标，像台标 | 徽标缩小到左上角 |
| **落版 / 定格（Hold）** | 最后一帧停住，让观众看清 | GOOD HUNTING 停留 |
| **字距（Tracking）** | 字和字之间的间距 | 字幕加宽字距显得“科技感” |

## 五、交付/工程

| 术语 | 白话 | 项目里用到 |
|---|---|---|
| **渲染（Render）** | 把代码/时间轴算成一帧帧图片，再压成视频 | render_frames.py |
| **编码（Encode）** | 把图片序列压成 mp4（H.264） | ffmpeg |
| **封装/混流（Mux）** | 把画面和声音合成一个文件 | ffmpeg mux |
| **CRF** | 压制质量参数，数字越小越清晰、文件越大（我们用 18） | 编码命令 |
| **faststart** | 让 mp4 在网页里点开就能播（不用等整段下载） | `-movflags +faststart` |

## 六、其他常问

- **60fps vs 30fps**：60 更顺滑、文件更大；用户拍板最终模板 60fps（要求逐帧对照原片 ≥95%）。
- **分辨率 1280×720 vs 1920×1080**：现在是 720p 原型；正式模板按 1080p/60fps 出。
- **“纱”不能动吗**：可以，但一般只做极慢的呼吸/漂移，动多了会抢主体。
