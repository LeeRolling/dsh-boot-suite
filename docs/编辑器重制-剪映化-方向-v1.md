# 编辑器重制 · 剪映化方向与规格 v1

> 记录时间：2026-10-29　状态：**方向草案，等用户确认后再进 M0**
> 触发：用户决定停做社媒宣传片；编辑器重制改走「借剪映 UI 布局」捷径（≈90%，不是 100% 克隆）。

## 0. 一句话

把编辑器从「配置面板 + 图层」改成**剪映式四区布局**（素材 / 预览 / 检查器 / 时间轴），让第一次打开的人凭剪映肌肉记忆就能上手；同时用一套**有限动作原语 + 中间表示（IR）**承接「圈转一会儿变成别的东西」这类需求——AI 只负责把话翻译成 IR，IR 可校验、可视化编辑、确定性渲染。

## 1. 目标与硬约束

1. **打开就熟悉**：90% 指布局与操作路径，不是像素克隆
2. **原有能力都在**：项目 / 模板 / 图层=片段 / 参数关键帧 / 转场 / Gate 断点 / 音频 / 导出 / 诊断
3. **WebUI**，本地优先（数据不出本机）
4. **接任意 AI**：用户自填 API key；默认自动接入用户本机 DSH
5. **不写代码也能表达**：「对象 + 动作 + 时间 + 状态变化」——核心难题
6. **不改旧数据**：旧 v1 `steps[]` / v2 `layers[]` 模板可读，迁移器兜底

## 2. 借鉴边界（合规与体验）

- **借**：分区、信息架构、操作路径、术语（轨道 / 分割 / 关键帧 / 转场）、快捷键习惯、播放器与时间轴的心智模型
- **不借**：Logo、图标集、品牌名、配色识别、字体原样、剪映商标性元素
- **合规提示**：界面布局与操作习惯通常不受版权保护；美术资产、图标、商标受保护。做法 = **同构布局 + 自研皮肤**（深色中性 + 单一强调色），不对外宣称「剪映同款」
- 参考：[OpenCut](https://github.com/OpenCut-app/OpenCut)（MIT，CapCut 替代品；classic 版 Next.js + React + Rust/WASM，新版从头重写中）

## 3. 布局规格（剪映式，90%）

### 3.1 启动页（「本地草稿」）

```
+------------------------------------------------------------------+
|  Logo/产品名            [导入] [新建项目] [设置] [账户]           |
+------------------------------------------------------------------+
| 最近项目（卡片网格：缩略图/名称/时长/修改时间）                    |
| 右键：打开 / 只读打开 / 重命名 / 复制 / 导出 / 备份 / 删除          |
+------------------------------------------------------------------+
|  [模板库]  [示例工程]                             版本 vX.Y.Z   |
+------------------------------------------------------------------+
```

### 3.2 主编辑页分区

| 区域 | 默认尺寸 | 内容 | 交互 |
|---|---|---|---|
| 顶栏 | 48px | 项目名、保存状态、撤销/重做、播放、吸附、导出、设置 | — |
| 左栏 | 260px（可拖 200–360） | 素材面板 tabs：媒体 / 音频 / 文本 / 贴纸 / 特效 / 转场 / 调节；网格缩略图 + 搜索 | 拖入时间轴或画布 |
| 中区 | flex | 预览播放器（16:9，深色底）+ 播放控制条 + 时间码 + 比例选择 | 空格播放；滚轮缩放画布 |
| 右栏 | 300px（可拖 240–380） | 检查器 tabs：画面 / 动画 / 音频；基础变换、关键帧、转场参数 | 改值即自动打帧 |
| 时间轴 | 320px（可拖 200–520） | 工具条（分割/删除/复制/吸附/缩放）+ 标尺 + 播放头 + 轨道 | 拖/剪/选/滚轮缩放 |
| 状态条 | 28px | 时间码、帧率、后端（WebGPU/WebGL2/Canvas2D）、缩放 | — |

### 3.3 素材面板 tabs（剪映同构）

- 媒体：本地图片 / 视频 / 音频 / 内建图形预设
- 音频：音乐 / 音效（含内建 UI 音效库）
- 文本：标题样式 / 字幕样式
- 贴纸：内建贴纸（含角色、表情包）
- 特效：画面特效（扫描线 / 故障 / 粒子 / 光效）
- 转场：交叉溶解 / 白闪 / 推移 / 故障 / 轮盘 / 叠加
- 调节：亮度 / 对比 / 饱和度 / 色温 / 锐化

### 3.4 时间轴规格

- 轨道：主轨（1 条，可换）+ 叠加轨（视频，无限）+ 音频轨（无限）
- 轨道头：静音 / 隐藏 / 锁定 / 音量（音频轨）/ 轨道高度拖拽
- 片段：缩略图/名称/时长；边缘拖动=修剪；拖动=移动；分割（Ctrl+B 同剪映）
- 转场块：拖到两个片段交界，时长可拉
- 关键帧：片段上菱形点，拖时刻、右键删、双击改缓动
- 播放头 + 时间码 + 缩放滑杆 + 吸附开关；Gate 断点显示为标尺上的红色三角

### 3.5 检查器（右栏）

- 画面：位置 / 缩放 / 旋转 / 不透明度 / 混合 / 裁切
- 动画：入场 / 出场 / 循环动画（动作卡）；参数关键帧 ◆
- 音频：音量 / 淡入 / 淡出 / 变速
- 每个参数一行：◆ 关键帧 + ↺ 重置 + 输入框 + 滑块

### 3.6 播放器

- 16:9 默认，支持 9:16 / 1:1 / 自定义；比例切换时画布自适应
- 播放控制：播放/暂停、逐帧（←/→）、循环、音量、全屏
- 预览质量：自动 / 高 / 流畅（大项目降级预览）

### 3.7 导出面板

- 格式：MP4(H.264) / WebM / GIF / PNG 序列
- 分辨率、帧率、码率、封面帧、字幕烧录、音频混音
- 导出前自检：缺失素材、关键帧越界、字体缺失、循环断点
- 导出走独立进程/后台任务，进度可取消

## 5. 创作模型（核心：怎么表达「圈转一会儿变别的」）

### 5.1 三层结构

```
意图层：用户说话 / 点动作卡          「圈转两秒，变成五角星」
   ↓ AI 翻译（或用户手动拖）
IR 层：anim-ir/1（JSON，可校验、可视化编辑）
   ↓ 编译器（确定性）
渲染层：逐帧画面（编辑器预览 = 导出结果）
```

**关键原则**：AI 只产出 IR，不产出代码；IR 的动作原语是白名单，参数有 schema 约束。

### 5.2 动作原语表 v1

| op | 作用 | 关键参数 | 用途 |
|---|---|---|---|
| `appear` / `disappear` | 出现/消失 | dur, from(scale/offset/alpha), ease | 入场出场 |
| `fade` | 不透明度 | to, dur | 淡入淡出 |
| `move` | 平移 | to{x,y}, dur, ease | 位移 |
| `scale` | 缩放 | to, dur, ease | 放大缩小 |
| `spin` | 旋转 | deg, dur, ease, axis | 转起来 |
| `wobble` | 抖动 | amp, freq, dur | 俏皮/故障 |
| `typewriter` | 打字机 | cps, cursor | 文字 |
| `draw` | 描边生长 | dur, dir | 线条/图形 |
| `morph` | 形状变形 | toShape, dur, ease | 圈→星/心/方 |
| `shatter` | 碎裂飞散 | count, speed, dur | 消失/重组前奏 |
| `reassemble` | 碎片聚拢 | from, dur | 变成别的东西 |
| `colorShift` | 变色 | to, dur | 强调 |
| `maskReveal` | 遮罩擦除 | dir, dur | 转场式出现 |
| `glitch` | 故障 | intensity, dur | 故障风 |
| `scan` | 扫描线 | speed, opacity, dur | 科技风 |

### 5.3 「圈转 2s → 变五角星」全链路

用户操作（不需要代码）：

1. 形状面板拖一个「圆」到画布
2. 动画 tab 拖「转起来」→ 检查器设 2 秒 / 2 圈 / 匀速
3. 接着拖「变形」→ 目标形状选「五角星」/ 0.6 秒 / 缓入缓出
4. 拖播放头预览；不满意就拖卡片时长、换目标形状

对应 IR：

```json
{
  "version": "anim-ir/1",
  "meta": { "fps": 60, "width": 1920, "height": 1080, "duration": 5000 },
  "layers": [{
    "id": "circle",
    "kind": "shape",
    "shape": { "type": "circle", "params": { "r": 160 } },
    "transform": { "x": 960, "y": 540, "scale": 1, "rotation": 0, "opacity": 1 },
    "cues": [
      { "at": 0,    "op": "appear", "dur": 300, "ease": "outBack" },
      { "at": 300,  "op": "spin",   "dur": 2000, "ease": "linear", "params": { "deg": 720 } },
      { "at": 2300, "op": "morph",  "dur": 600, "ease": "inOut", "to": { "shape": { "type": "star", "params": { "points": 5, "inner": 0.45 } } } },
      { "at": 2900, "op": "hold" }
    ]
  }]
}
```

编辑器里这条链 = 一段「动作卡链」：`出现 → 旋转 2s → 变形 0.6s → 保持`，可拖长度、换目标、调曲线。

### 5.4 变形（morph）怎么真的做出来

| 对象 | 方案 | 说明 |
|---|---|---|
| 形状（圆/方/星/心/水滴/多边形） | **参数化形状族** | 全部由同一个 `path(params)` 生成器产生（N 个采样点），morph = 参数插值 + 路径插值；圆→五角星只是 `points` 从 ∞ 到 5、`inner` 从 1 到 0.45 |
| 文字 / 图片 | **碎-聚** 或 **交叉淡化** | 不承诺真形态插值；`shatter` 打散 → `reassemble` 成目标，视觉上就是「变成别的东西」 |
| 复杂 logo | 分阶段：挤压 → 遮罩擦除 → 新形状浮现 | 第一版不开放 |

第一版范围：形状族 morph + 碎聚；其余给「预设 morph 对」，AI 只能从枚举里选，不自由生成路径。

### 5.5 触发器（不只是时间轴）

- `at`：绝对时间（默认）
- `after: cueId`：上一个动作结束后触发（「转完再变」）
- `gate`：用户点击/按键才继续（复用 Gate）
- `beat`：对齐音频节拍（BPM 标记）

### 5.6 配方库（拖即用，首批 10 个）

弹入、转起来、呼吸循环、打字机、扫描线、故障闪、描边生长、粒子聚拢、变形、爆炸重组。

## 6. AI 接入

### 6.1 Provider 抽象

```ts
interface ProviderConfig {
  id: string; label: string
  kind: 'dsh' | 'openai-compatible' | 'anthropic-compatible' | 'cli'
  baseURL?: string; model: string; keyRef?: string
  capabilities: ('ir' | 'text' | 'image')[]
}
```

- **dsh**：本机 DSH（自动发现端口/profile，无需 key）——默认、开箱即用
- **openai-compatible**：DeepSeek / GLM / Kimi / Qwen / OpenAI 等，baseURL + key
- **anthropic-compatible**：兼容 Claude 协议的网关
- **cli**：本地 Codex CLI / Claude Code（可选，用户有就接）

### 6.2 默认接入自己的 DSH

- 启动时探测本机 DSH（读 `~/.dsh` 配置里的端口/profile），能连上就设为默认 provider
- 连不上就降级为「预设模式」（无 AI，也能用配方库和手动编辑）

### 6.3 用户 key 存储

- 存本机（`%APPDATA%\<产品>\secrets.json`，或复用 DSH 的配置位置），**不进项目包、不上传**
- UI 只显示尾号；「测试连接」按钮；删除即抹掉
- 导出工程时自动剔除 key（写包前扫描一层）

### 6.4 契约与失败处理

- 模型输出必须是合法 `anim-ir/1` JSON：JSON Schema 校验 → 失败把错误回传重试（最多 2 次）→ 再失败回退模板
- 每次 AI 改动生成 **diff**，编辑器里可预览/接受/撤销
- 成本显示（tokens/估算费用）+ 单次上限

### 6.5 AI 使用场景

1. 一句话生成整片（开场→主体→结尾）
2. 局部修改：「这个圆再转快一点」「换成蓝色」
3. 文案/字幕生成与排版
4. 素材建议（从素材池挑图/音效）

### 6.6 可选：MCP

把编辑器暴露成 MCP server（`import_ir` / `add_cue` / `render_preview`），让 DSH / Codex 等 agent 直接操作时间轴——这是「AI 接入任何种类」的更深一层。

## 7. 技术架构（在蓝图 v2 上增量）

```
packages/
  schema/       anim-ir 类型 + JSON Schema + 迁移
  core/         时间轴数学、插值、缓动（纯函数）
  renderer/     WebGPU / WebGL2 / Canvas2D + 自动降级（复用现有引擎）
  editor/       WebUI（React + Vite + TS，可脱离 DSH 开发）
  host/         DSH 插件：本地 HTTP（项目 CRUD、素材、备份、导出任务）
  ai/           provider 抽象 + IR 校验 + diff
  cli/          导出/批处理（可选）
```

- 前端栈：React + Vite + TypeScript + zustand；时间轴用 canvas 绘制（性能），面板用 DOM
- **预览与导出共用同一渲染器**（所见即所得），导出离线逐帧，不引 Remotion
- 不引 Next.js（本地 SPA 更轻，OpenCut 用 Next.js 是它的历史包袱，不照搬）

## 8. 里程碑

| 阶段 | 内容 | 验收 |
|---|---|---|
| **M0** | 可点原型：静态布局 + mock 数据 + 拖拽骨架（无真实渲染） | 你打开能说「像剪映」并指出要改的地方 |
| **M1** | 一句话 → IR → 预览（3 个原语：appear/spin/morph） | 输入「圈转两秒变五角星」能出片 |
| **M2** | 时间轴 + 关键帧 + 主要面板全部可用 | 手不写 JSON 能做出 5 秒开场 |
| **M3** | 导出 + AI provider 完整接入 + 旧模板迁移 | 导出 MP4 且与预览一致 |

## 10. 风险

| 风险 | 处理 |
|---|---|
| 范围失控成「半个 AE」 | 原语白名单 + 每阶段冻结；不做遮罩/表达式/父子关系 |
| 剪映习惯随版本漂移 | 只锁基础布局与操作路径，不追新功能 |
| AI 生成不可控 | IR 校验 + diff 预览 + 回退模板 |
| 双渲染器结果不一致 | 编辑器与导出共用同一 renderer |
| 合规 | 自研皮肤、不复制图标/logo/品牌名 |
| 素材/字体缺失 | 缺字段回落：占位图、等宽字体、静音 |
