# 致每一位使用 dsh-boot-suite 的朋友

大家好，我是 LeeRolling，dsh-boot-suite 的作者。

最近一段时间，插件连续出现了几个本不该发生的问题：

- 选择「内置（档案暖白）」后，开机动画直接秒退；
- 「纱的浓度」拖到 0% 仍残留半层纱，调了像没调；
- 浅色 / 深色外观切换后，聊天区和侧栏没有跟着变；
- DSH 桌面 0.2.2-rc.1 上，部分用户遇到 splash.js 加载失败、客户端起不来；
- 版本号与 CI 校验也出现过疏漏，发布流程一度变红。

这些问题不是你们的使用方式不对，也不是环境太特殊，而是我在测试、兼容性验证和发布把关上做得不够。我把「能跑」当成了「可以发」，把一些本应在发布前覆盖的场景留到了用户手里。对此，我向每一位被打断、被吓到、被迫花时间排查的朋友郑重道歉。

目前 v2.16.13 已修复上述问题：空模板回落默认、纱浓度两端同步、主题实时跟随、桌面静态资源不再被信任栅栏误拦；CI 已恢复绿色，相关回归测试也已补上。

我知道一句道歉不能抵消麻烦。接下来我会做到：

1. 每个已确认的 bug 先补回归测试，再谈修复；
2. CI 不绿不发版，版本号、发布资产与 npm 三处必须对齐；
3. 桌面端每个 DSH 版本先做一次真实启动验证；
4. 每天读 Issue 和通知，不再让问题躺太久；
5. 发版放慢，不再「先发再补」。

如果你更新后仍遇到问题，请带上插件版本、DSH 版本和 `~/.dsh/boot-suite-diag.log` 的尾部找我；我会逐条看。

给大家添麻烦了，对不起。也谢谢还愿意留下来反馈的你们。

LeeRolling  
2026-11-12
