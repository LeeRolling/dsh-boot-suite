# 引擎能力清单（2.4.0）

> 用途：找参考、提需求时先看这张表，判断「改参数」还是「要加引擎」。
> 每一条都对应代码里的实际能力，不是规划。

## 一、现在改模板就能做到的（不用动引擎）

| 能力 | 字段 | 说明 |
|---|---|---|
| 分幕数 | `steps[]` | 1–24 幕，任意增删 |
| 每幕文案 | `zh` / `en` / `log` / `logEn` / `badge` | 中文主字、英文副标题、底部日志、阶段标记 |
| 停留时长 | `hold` | 毫秒；实际按「与配音取较长者」自动延展 |
| 要不要点按钮 | `action` | `auto` 自动过 / `grant` 授权 / `confirm` 确认 |
| 按钮文案 | `btnZh` / `btnEn` | 仅 `grant` / `confirm` 有 |
| 进度条 | `progress` | 0–1，不填按幕序自动均分 |
| 逐幕画面元素 | `assembleLogo` / `reticle` / `hex` | 鲸鱼组装 / 环形准星 / 六边形网络 |
| 配色 | `theme.*` | 底色、次级底色、主字、次级字、灰字、纱、强调、故障 A/B、明暗版式 |
| 自带配音 | `assets` | 每句一个音频文件，独立于全局素材 |
| 身份与页脚 | 配置项 | 身份名称、编号、权限等级、页脚文案 |

## 二、固定不动、暂时改不了的

| 元素 | 现状 | 想改需要 |
|---|---|---|
| 开场四段 | 黑幕 → 标识 → 色扫 → 过曝洗白 → 底板 | 引擎 v2：可编排的转场序列 |
| 中央区构图 | 状态行 + 分隔线 + 鲸鱼 + 虚线，位置固定 | 引擎 v2：布局槽位（上/中/下、左/右） |
| 品牌区 | 左上角三行 + 右下 `POWERED BY` | 允许部分字段覆盖（`brand1/2/3` 已有，但不全） |
| 字体 | DIN 风格 / 等宽 / 雅黑，系统字体栈 | 引擎 v2：可挂自定义字体（打包体积） |
| 背景装饰 | 右侧极淡面板、竖条、扫描线 | 引擎 v2：装饰层开关与密度 |
| 环形准星形状 | 一圈圆弧 + 扫描线 | 引擎 v2：形状参数（半径/厚度/缺口/转速） |

## 三、要做「另一种完全不同的动画」缺什么（引擎 v2 计划）

| 能力 | 优先级 | 说明 |
|---|---|---|
| **图形层** | 高 | SVG 路径 / 图形库（圆、线、网格、粒子），每个可设位置、大小、旋转、颜色、出场时机 |
| **效果层** | 高 | 扫描、故障、模糊、辉光、遮罩、逐字、打字机，可组合、可设时长与曲线 |
| **转场层** | 高 | 幕与幕之间的过场（硬切/洗白/推镜/溶解），现在只有一套写死的开场 |
| **布局槽位** | 中 | 文字块能放中间/左下/右下，而不是固定中央 |
| **音频挂钩** | 中 | 每幕可挂多个音（人声 + 音效），指定相对时机 |
| **自定义字体** | 低 | 模板带字体文件（体积大，谨慎） |

## 四、给参考时的最省事格式

> 「像 ___（图/片/网址），主色 ___，动效是 ___ + ___，构图是 ___（字在哪、图在哪），
> 我要新加的是 ___」

我会回你三种结论之一：

- **能做，改参数就行**（今天就能出）
- **要加一个元素/效果**（引擎 v2 的一小块，半天到一天）
- **要重做编排**（新的动画类型，需要新的一层）
