# 编辑器 v2 规格：时间线 + 画布

> 需求来源（LeeRolling，2026-10-18）：
> "需要一个带时间线轨道和画布的编辑器，把我们现在所有的素材整合成一个包，用户丢上去就可以用。"
> "完全记录我修改的每一点：从 A 跑到 B、怎么跑、挪了多少 px、有没有放大缩小、加了什么背景/动效……"

## 一、这个编辑器的本质

不是"让用户写 JSON"，也不是"让用户描述感觉"，而是**所见即所得的时间线**：

- 左边：图层列表
- 中间：画布（实时预览）
- 下面：时间线轨道 + 关键帧 + 播放头
- 右边：属性面板（当前播放头所在时刻的值）

用户拖一下，编辑器就记下"这个图层在 t=900ms 时 y=0、opacity=1"——
**他不需要知道 px 和 easing 是什么，他只要看到东西动。**

## 二、数据模型（v2 模板）

现有 v1 是"分幕"（`steps[]`）：适合"一步一步过"的仪式感动画。
v2 是"图层 + 关键帧"：适合任意编排，也是时间线编辑器唯一能写的形式。
两者共存：老模板继续走 steps，新模板走 layers。

```json
{
  "schemaVersion": 2,
  "id": "my-template",
  "duration": 6200,
  "fps": 60,
  "theme": { "bg": "#05070a", "ink": "#d7ffe6", "accent": "#58f08a", "mode": "dark" },
  "layers": [
    {
      "id": "title",
      "type": "text",
      "text": "建立安全通道",
      "en": "SECURE CHANNEL",
      "pos": [640, 380],
      "font": { "size": 44, "tracking": 0.08, "weight": 500 },
      "keyframes": [
        { "t": 300, "opacity": 0, "offsetY": 20, "scale": 0.98 },
        { "t": 900, "opacity": 1, "offsetY": 0, "scale": 1, "ease": "spring:180/24" }
      ]
    },
    { "id": "rule", "type": "line", "pos": [640, 440], "width": 520,
      "keyframes": [ { "t": 700, "reveal": 0 }, { "t": 1200, "reveal": 1 } ] },
    { "id": "avatar", "type": "image", "src": "assets/avatar.png", "pos": [200, 300], "size": [128, 160],
      "keyframes": [ { "t": 1600, "opacity": 0, "scale": 1.04 }, { "t": 2000, "opacity": 1, "scale": 1 } ] }
  ],
  "effects": [
    { "type": "scanline", "opacity": 0.55, "from": 0, "to": 99999 },
    { "type": "glitch", "at": 4800, "duration": 260 }
  ],
  "audio": [ { "t": 300, "slot": "line-1" }, { "t": 1600, "slot": "line-2" } ]
}
```

关键约定：

- **时间单位 ms，全部相对于动画开始**（编辑器里看到的尺子就是它）
- 关键帧之间线性/贝塞尔/弹簧插值，`ease` 可省略（默认缓出）
- 图层坐标系 = 画布逻辑坐标（1280×720），实际渲染按窗口等比缩放
- 缺字段一律回落：图没了画个占位，字体没了用等宽，音没了不播

## 三、编辑器界面（复用现有编辑器外壳）

```
+--------------------------------------------------------------+
| 顶栏：[▶ 播放] [⏸] [时间 0:02.34 / 0:06.20]  [保存] [导出]    |
+----------------+---------------------------------------------+
| 图层            |                                             |
|  ● 标题         |              画布（实时预览）                |
|  ● 分隔线       |                                             |
|  ● 头像         |                                             |
|  + 添加图层     |                                             |
+----------------+---------------------------------------------+
|  0s      1s      2s      3s      4s      5s      6s         |
| 标题    ◆————————◆                                          |
| 分隔线          ◆————◆                                      |
| 头像                  ◆————————◆                           |
+--------------------------------------------------------------+
| 属性（播放头 0:01.20）：opacity 0.86 · y +3px · scale 0.995  |
+--------------------------------------------------------------+
```

交互（v1 必须有的）：

1. 拖播放头 → 画布实时跟着变
2. 选图层 → 属性面板显示当前时刻的值；改属性 = 在当前时刻插关键帧
3. 拖关键帧 → 改时刻；右键 → 删除
4. 拖画布里的图层 → 直接改位置（自动落关键帧）
5. 时间线缩放（滚轮）+ 吸附（10ms）
6. 导出 = 当前模板 JSON；保存 = 写进 `~/.dsh/startup-templates/<id>/`

## 四、分阶段计划

| 阶段 | 内容 | 产出 | 估时 |
|---|---|---|---|
| **M1 数据模型 + 渲染器** | 引擎支持 `layers[]` 与关键帧插值；跟现有 steps 共存 | 用 JSON 手写一个"标题从下往上浮现"的动画，能播 | 2 天 |
| **M2 时间线 UI** | 图层列表 / 画布 / 轨道 / 关键帧 / 播放头 / 属性面板 | 不写 JSON 也能做出 M1 那个动画 | 2–3 天 |
| **M3 素材与效果库** | 图片层、打字机、扫描线、故障、描线、音频打点 | 拖进图层就能用 | 持续 |
| **M4 导出与商店** | 导出/导入模板包、商店一键安装、编辑器内预览 GIF | 用户"丢上去就能用" | 1 天 |

## 五、与现有东西的关系

- **不推翻 v1**：`steps[]` 继续服务"档案暖白/深海声呐/磷光终端"这类仪式感动画
- **v2 是给"任意编排"用的**：描线动画、图片开场、复杂字号排版都靠它
- **同一套渲染器**：v1 与 v2 共用主题、字体、声音、结束交接、首帧注入
- **同一个编辑器外壳**：现在是"表单式"，加一个"时间线式"标签页

## 六、风险与边界

| 风险 | 处理 |
|---|---|
| 做到"半个 AE"失控 | v1 只做 3 种图层 + 2 种插值，不碰遮罩/表达式/父子关系 |
| 性能 | 图层数上限定 40；关键帧每层上限定 32；只用 transform/opacity |
| 用户做出很丑的东西 | 提供 3 套预设起步（终端 / 档案 / 深海），改值不改结构 |
| 手机/窄屏 | 编辑器要求 ≥1100px，否则提示"用桌面打开" |
