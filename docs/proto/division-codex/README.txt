新版：参数化 SVG + JavaScript 动画。双击 index.html 即可使用，不需要服务器或网络。
用户名、提示标题和正文可在右侧实时编辑，保存在浏览器本地；修改 config.js 可设置项目默认内容。浏览器中已有设置时先点恢复默认，才会采用新的默认配置。
圆环、刻度、旋转、加载百分比由 app.js 和 config.js 参数生成，无视频、位图序列或逐帧绘制数据依赖。
ISAC 语音框复用上级项目的语音绘图逻辑，代码已复制到 voice.js，因此本文件夹可独立复制使用。默认在加载阶段出现，位于加载中下方约两行距离，可调整间隔。
导入音频后按设置的开始时间同步播放并驱动波形；到动画总时长结束时停止，长语音可在 config.js 调整 duration。音频仅留在本机，重新打开需再次选择。
当前是可编辑的几何重建版本，不是像素级逐帧匹配。旧的大体积项目没有删除，新版不依赖旧目录。

第二轮动作修订：motion.js 提供分层展开、3.05–4.30秒退场、重新展开、连接扫描脉冲、外圈呼吸及提示区闪入。ISAC 默认宽度由440改为220，宽高均减半。新增60fps逐帧前后检查。参数曲线是对原片的近似重建，非像素级匹配。
