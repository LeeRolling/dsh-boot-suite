## 2. 四批共 40 条规律（标题索引）

**批 1（A–G/H/Z/R/V，75 篇）**：单核动作律；三段式弹性入场（预备→过冲→回弹）；镂空要真挖（destination-out）；图层顺序就是风格；做形变先收敛到中介简形；metaball 可伪造（模糊 20px+卡 alpha）；低分辨率画布+整数倍最近邻+steps()；玻璃/极光是配方不是灵感；图表三通道同步；花字三层描边+8 帧 overshoot。

**批 2（L/X，90 篇）**：on twos 12fps 演人物、ones 24fps 走相机；转场只用媒介自己的动作；字幕停留有公式（≥max(1.8s, 语音+0.6s)，CJK 字÷4.5+1.5s）；每 0.5–1 s 一个动作（hold 也留 2–5% 蠕变）；一屏一结论、比较双方同屏 ≥2.5 s；数字必须可量测/可追溯；增长与拆解用「装配」不用缩放；节奏交给外部网格（BPM/拍点）；相机永不越界；世界自洽（光从媒介来）。

**批 3（K/M，78 篇）**：确定性优先于随机性；交付形态写死（单文件+原生 Canvas）；自检清单写成疑问句；禁项比选项更能定义风格；形式即论证；转场必须有因果；首末帧一致=零成本循环；M 组节奏量化到秒；讲解骨架固定五幕；音画同源+后期指标写进提示词。

**批 4（O，98 篇）**：时长先定风格后谈；唯一彩色给主角；每篇必须有写死尺寸的招牌镜头；用介质做转场；给「暗」和「多」设上限；参数写到荒谬具体（线宽 1/800、网点 1/250、颗粒 ±3%、错版 1–2px）；能用摄影参数就别用形容词；一镜到底与全硬切是二元；「避免」比「像」更有力；把情绪翻译成物理量。

### 归纳成编辑器能执行的 6 类

1. **风格 = 强约束参数包**（色板/线宽/字体/材质/颗粒/错版），不是形容词。
2. **运动 = 入场-停留-退场三段 + 时长预算**，每 0.5–1 s 一个动作脉冲。
3. **版式 = 数字约束**（安全区、字号阶梯、单屏一结论、比较同屏 ≥2.5s）。
4. **节奏 = 外部网格**（BPM/拍点/字幕公式），转场必须有因果、用媒介动作。
5. **确定性 = 交付前提**（固定种子、仅 init 取数、顺序即接口、`__ready` 握手）。
6. **禁项清单 = 风格的另一半**（每篇约 3 条「避免」）。

## 3. 代码层学习（详见 `代码学习-超越五条.md`，413 行）

**20 条代码级规律 R1–R20 + 17 条新增表 + 10 条 anim-ir 硬约束 C1–C10 + 15 条坑。** 最该带走的 5 条：

1. **时间入口四件套**：`__seek / __play / __duration / __ready`。示例里 Opus 版只给 2 个、DeepSeek 版 0 个——纯函数 `render(t)` 只是口号，缺钩子就抓不了帧。
2. **时长是帧数问题**：`frames = round(dur*fps)` 并回写；`seek` 语义 `wrap|clamp` 必须显式声明（同一提示词两个模型给出相反语义）。
3. **DPR 分流**：主画布 = 输出分辨率 1:1，`dpr` 只进离屏；缩放三选一（CSS 公式/JS fit/transform）。
4. **确定性随机四律**：固定种子 + 仅 init 取数 + 顺序即接口 + 按 id 派生子种子（数组重排不改画面）。
5. **状态卫生 + 叠加分工**：`beginFrame()` 每帧复位；`lighter/multiply/overlay` 只当层用，改完必回 `source-over`。

事实核查：26 篇参考实现里 `strokeText` 出现 **0 次**（文字描边必须引擎补）；`prefers-reduced-motion` 全库 **0 处**；官方样例 A1 自己在做帧积分，违反 B3 立的规矩（坑 #1）。

## 4. 对编辑器的直接落点

1. **风格库面板**：`style.catalog.json`（341 条，含 tier/色板/时长/规律）作为选型数据源；画像卡片 = 静帧 + 3 个关键词 + 2 条禁忌 + 时长。
2. **AI few-shot 教材**：按 tier 取样本——「可执行」257 条直接喂结构化字段，「意象」84 条先补色值/线宽再升可执行（K 组 38 条只能当语义标签）。
3. **anim-ir 增补**（来自 C1–C10）：`fps/frames/duration` 显式、`seekMode`、`seed` 与 `rngFor(id)`、`ready` 握手、`stroke` 文本、`reducedMotion` 降级、上下文字体回退、素材缺失占位、失败重试。
4. **内置校验**（把「自检清单」变成规则）：t=0 是否空白、同一 t 两次渲染是否一致、首末帧是否可循环、文字是否越界、字体是否回退、时长是否超预算。
5. **原语补充清单**：从 40 条规律里抽出编辑器缺的原语（镂空、metaball 式模糊+阈值、整数倍像素风、装配式增长、三层描边花字、图表三通道、介质转场族）。
