## 4. 最值得学的 10 条规律

1. **单核动作律：同一时刻只允许一个 hero 动作。** 10 秒要讲 6 个信息点，靠的不是并行而是排序（V3；F3 分屏也是「左一个问题、右一个问题」轮流抢注意力）。
2. **三段式弹性入场：预备 → 过冲 → 回弹，缺一段就退化成 PPT 飞入。** 扁平风格的全部「手感」都在这里（V3 的 `cubic-bezier(0.34,1.56,0.64,1)`、A3 大字冲击、B5 呼吸的圆）。
3. **镂空要真挖，不要盖色。** Z5 用 `destination-out` 逐帧重生成 `layerTop`，每圈晚 0.18 s、每孔 0.35 s；盖一块底色永远做不出纸的厚度（Z5、E2 剪纸层叠同理）。
4. **图层顺序就是风格本身。** V9 拼贴的硬顺序「背景纸纹 → 大形色块 → 照片剪影 → 涂鸦/胶带 → 颗粒层」顺序一乱就变成贴图拼盘；Z5 的「底盘 → 主盘 → 镂空 → 盖章」同理。
5. **做形变先收敛到中介简形。** A → 圆/胶囊 → B 各 8–12 帧，顶点数一致、首顶点方位对应，否则中点必打结（V6；打结在静帧最明显，必须出中点检查帧）。
6. **metaball 可以伪造：模糊 20px+ → 卡紧 alpha 阈值。** 再叠「拉丝-断裂-2–3 帧回弹」与次级液滴延迟 2–3 帧，黏稠感就成立了，不需要真物理（V14；A5 字散了再聚同一路数）。
7. **低分辨率画布 + 整数倍最近邻 + `steps()` 阶梯时序。** 像素风（V13 内部 320×180 ×6）与 R5 的 480×270 是同一招；平滑缓动一上来立刻破功。
8. **玻璃与极光是配方，不是灵感。** 玻璃卡 = `backdrop-filter blur 20–40px` + 白 5–10% 填充 + 1px 白 30% 内描边 + 大圆角；极光团只用邻近色 + 全局 3–5% 噪点防 banding（V10）。
9. **图表的三个通道必须同步：柱长、数字跳变、折线补完。** 少任何一个都会显得「图没做完」（F1 图表生长；V7 进一步要求柱子按比例、数字前后一致）。
10. **花字三层描边 + 8 帧 overshoot + 比音画晚 2–3 帧。** 填充色 + 粗白描边 + 彩色外描边/投影；`scale 0→1.15→1.0` 约 8 帧；出现比音效晚 2–3 帧反而更自然（V15）。

## 5. 各组风格族概述

**A-G_代码样片（26 篇，全部可执行）**
本组是全库唯一「能直接跑」的一组：每个 md 都给出 `S.XX(c, w, h, t, s)` 形式的 Canvas 2D 实现，配 `_公共函数.js` 里的 `rng / lerp / ss / eOut / eBack / glowDot / offscreen / paperTex / mixHex / nz`，画法是 `draw(t)` 纯函数 + 种子随机（如 `mulberry32(2026)`），同一秒永远画出同一帧。题材覆盖文字动力学（A1 字雨、A3 大字冲击、A4 字的隧道）、粒子（B3 粒子聚形是全批唯一声明 19.2 s 循环的一篇）、水墨与线条（C1 水墨晕开、C2 一笔画）、天气光景（D1 雨窗、D4 天亮）、几何/剪纸/字符画（E1–E3）、信息图（F1–F3）与复古质感（G1 老胶片、G2 信号故障）。多数篇目没有声明时长，靠 `t % N` 的循环周期设定节奏，这类「隐式节拍」是本组的共同语法。

**H_现成版式（12 篇，1 可执行 + 11 意象）**
现成版式组像一个海报选型清单：H1 Biennale Yellow 是唯一施工图（纸 #F2E9D2 / 日 #F6C23E / 墨 #1D2A68，`strokeRect(64,64,1792,952)` 外框、y=148/932 双横线、太阳圆心 (1380,470) r=250、r410→421（每 5 条到 432）共 120 条刻度、标题 x=100 基线 560/770、默认 6 s），其余 11 篇只有「标题 + 一句话 + 关键词」（新粗野主义、羊皮纸钴蓝、倾斜花体、工业报纸、胶囊 + Bodoni、极简留白、钴蓝网格 + Newsreader、Bebas Neue、Archivo Black、3px 炭灰描边硬投影、绿粉奶油）。它们更适合当「构图母版」而不是「动画规格」——真正可迁移的是 H1 里那套「坐标系 + 刻度环 + 双横线」的骨架。

**Z_中国风（15 篇，1 可执行 + 14 意象）**
选题覆盖水墨、工笔、写意、山水、年画、皮影、敦煌、青花、木版画、脸谱、书法、水墨漫画、彩铅、水彩科普卡与剪纸，但除 Z5 外全是 8 行中英对照的一句话描述，`palette` 只能留空（原文只给色名）。Z5 剪纸是这批里唯一的施工图：纸 #F1E8D4 + 亮红 #C8102E + 深红 #8F0B22，2000 条纸纤维，`layerBase r=452 / layerTop r=404`，48 孔 / 24 水滴 / 12 花瓣 / 12 菱形 / 12 圆点 / 12 内圈花瓣的同心圈全部给死半径与宽度，投影 `rgba(70,12,12,0.38) blur16 offset(5,9)`，时间轴 0–0.8 s 展开 → 1.2–4 s 镂空由外向内 → 4–4.4 s 盖章（`scale 1.15→1.0`）→ ±0.6 度摆动周期 6 s → 最后一秒静止，默认 12 s。中国风要落地，#F1E8D4 这类「纸色 + 单一正色」的配比关系比具体纹样更可复用。

**R_照参考学来的（7 篇，全部意象）**
每篇固定 22 行：标题/分类/「长什么样」→ `## 风格提示词` → `## 补充`（学的是哪张参考、相近的旧编号、定死的画法）。它们不给 hex（只有「冷青/红粉/橙光」「墨纸朱红」这类色名），但「定死的画法」里全是硬参数：R2 平涂 + 硬边阴影 + 硬边高光 + 有色描边、拉丝后画招牌、微微歪；R3 四色封顶 + 整块深紫阴影 + 压网点 + 不发光不虚化；R4 一个颜色分 7 层远近；R5 480×270 画布 + 28 色调色板 + 拜耳抖动 + 放大 4 倍关平滑 + 从连续骨骼每帧重画（明确不做 8 fps 跳格）；R6 只有墨纸朱红、霓虹只点一点青、竖排题字与印章收画面；R7 只有天是渐变其余平涂、越远楼越接近天色、发光只给霓虹字/灯串/小灯。这组是「限色/限发光/限层数」的负向约束集合，价值高于任何色板。

**V_mg-styles-15（15 篇，全部可执行）**
提示词工程完成度最高的一组：每篇顶部有原片元数据（标题 · 1920×1080 · 30 fps · 10 秒 · AI 评审终评 x.xx/10），正文是一个 `text` 提示词块（`# Style` / `# Output (fixed)` / `# Suggested technical route` / `# Creative seed` / `# Signature features`），输出参数全篇统一为 `exactly 10.000 s`、AAC 48 kHz、−14 LUFS、真峰 ≤ −1 dBTP，仅 V5 走 24 fps / 240 帧、V15 为竖屏 1080×1920。风格谱系从 2D 系（V1 逐帧手绘、V2 等距 2.5D、V3 扁平矢量、V4 线条画、V6 形变）到 3D 与材质系（V5 3D 渲染、V10 极光与毛玻璃、V14 液态流动）、版式与图像系（V7 贴纸讲解、V9 拼贴、V13 像素）、潮流与综艺系（V8 赛博朋克界面、V11 包豪斯、V12 合成波 VHS、V15 综艺花字）。它最大的启示是「固定输出契约 + 变化视觉种子」：10 秒 / 300 帧 / −14 LUFS 是不动的，换来的是风格之间可以公平比较、也能批量套模板。

## 6. 字段口径与已知空缺

- `durationDeclared` 只填原文显式声明的秒数；`motion.declaredDur` 与之保持一致。代码推导出的循环周期一律写进 `assumptions`，不冒充声明。
- `palette` 只收原文给出的 hex；只有色名的篇目留 `[]` 并在 `assumptions` 注明原文只给色名，避免下游误把猜测当规格。
- Z7（写意）原文注明「动法见 M12」，本批不含 M 组，故其 `motion` 只保留静态描述。
- 意象组（尤其 H2–H12、Z1–Z4/Z6–Z15）的 `type.sizeRatio` 多为 `null`：原文没给字号/模数，未做补齐。
