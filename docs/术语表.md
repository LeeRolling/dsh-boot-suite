# 术语表：我们这套东西叫什么

> 用途：找参考、跟我描述需求、写模板文档时用同一套词。

## 整体

| 中文 | 英文 / 关键词 | 说明 |
|---|---|---|
| 开机动画 | **boot animation** / **boot sequence** / **startup sequence** | 最通用的说法 |
| 启动序列（分幕） | **staged boot sequence** / **cinematic boot intro** | 强调「分几幕演」，不是一张启动图 |
| 开场标题序列 | **title sequence** / **opening titles** | 影视术语，最贴我们：一串镜头 + 文案 + 收尾 |
| 启动界面（首屏） | **splash screen** / **launch screen** | 只指那一屏，不强调过程 |
| 界面动效设计 | **UI motion design** / **interface animation** | 搜参考时最好用的词 |
| 逐字打出 | **typewriter effect** / **kinetic typography** | 我们的英文副标题就是 |
| 分幕 / 一幕 | **scene** / **act** / **step** | 我们的 template.json 里叫 `steps` |

## 视觉元素（搜参考时直接用）

| 中文 | 英文关键词 | 在我们模板里的字段 |
|---|---|---|
| 环形准星 / 瞄准环 | **reticle** / **targeting ring** / **HUD ring** | `reticle: true` |
| 六边形网格 | **hex grid** / **honeycomb** | `hex: true` |
| 标识组装 | **logo assembly** / **mark build-up** | `assembleLogo: true` |
| 过曝洗白 | **overexposure** / **white-out flash** | 内建过场（不可关） |
| 色散故障 | **chromatic aberration** / **glitch** / **RGB split** | `glitchA/glitchB` 颜色 |
| 扫描线 | **scanlines** / **CRT** | 内建 |
| 声呐扫描 / 雷达 | **sonar sweep** / **radar sweep** | 目前未参数化（计划中） |
| 傅里叶本轮 | **epicycles** / **Fourier drawing** | 计划中 |
| 深度计 | **depth gauge** | 文案层面模拟 |
| 仪表盘 HUD | **heads-up display** / **sci-fi HUD** | 搜 UI 参考的王牌关键词 |
| 技术档案 / 蓝图 | **technical dossier** / **blueprint** / **document UI** | 「档案暖白」那套 |
| 等宽字距小字 | **monospace caption** / **tracked-out type** | `badge` / `logEn` |
| 右上/右下角读数 | **corner readout** / **HUD data block** | 固定装饰 |
| 进度条 | **progress bar** / **slats** | `progress` |

## 找参考时最好用的搜索词（组合用）

- `boot sequence animation`
- `sci-fi HUD boot`
- `system startup animation ui`
- `title sequence design`
- `UI motion design intro`
- `terminal boot sequence animation`
- `reticle HUD animation`
- `sonar radar UI animation`
- `epicycles animation`

平台建议：Dribbble（搜 `boot sequence` / `HUD`）、Behance（`title sequence`）、
Vimeo（`motion design reel`）、CodePen（`CSS boot animation`）、
以及直接搜「Anime UI 启动界面」这类参考片。

## 跟我描述需求的最短格式

> 「像 ___（参考图/片），主色 ___，动效是 ___ + ___，构图是 ___，
> 我想要的新东西是 ___」

例子：
> 「像攻壳的启动画面，主色深蓝，动效是逐字 + 横向扫描，构图是中央大字 + 右下角读数，我想把环改成声呐波纹。」
