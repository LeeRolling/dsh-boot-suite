## 它的动画模型：命令式 async 编排，不是时间线

```js
function createShow(stage, options) {
  function sleep(ms) { /* 可取消：跳过时整条链一起 reject */ }
  function later(fn, ms) { /* 可取消的 setTimeout */ }
  async function playBoot() {
    for (const item of sorted) { await sleep(300); item.el.classList.add('draw'); }
  }
}
```

- **`sleep` / `later` 都可取消**：用户跳过时，`cancelled` 一置位，整条 Promise 链一起 reject，
  不会出现"跳过之后还有定时器在后台改 DOM"这种鬼故事。这是它做得最稳的一点。
- **两级模式**：`simple`（只演 logo）/ `full`（logo → HUD → 覆盖阶段）。
  简单模式完全不碰 `#app` 的 DOM，避免没挂载的节点报错。
- **分阶段 `await`**，每段自己算时长；没有统一时间轴，改顺序要改代码。

### 和我们的区别

| | 550C | 我们 |
| --- | --- | --- |
| 编排方式 | 命令式 async 链 | 声明式时间线（关键帧 + 时间窗） |
| 编辑 | 改代码 | 编辑器里拖 |
| 跳过/取消 | 全局 cancelled 标志 | `__DSH_STARTUP_API__.skip()` |
| 复用 | 一个模板 | 模板 + 图层/效果积木 |

**可以借的**：全局取消标志要覆盖所有定时器（我们已经有 skip，但部分 setTimeout 没接取消）；
两级模式（simple / full）值得学——我们可以在模板里加 `minimal` 变体，低配机器只演主视觉。

## 舞台结构：一层层叠出来的 HUD

```html
<div class="stage">
  <div class="grid"></div>      <!-- 网格 -->
  <div class="scan"></div>      <!-- 扫描线 -->
  <div class="vignette"></div>  <!-- 暗角 -->
  <div class="frame"></div>     <!-- 边框 -->
  <div class="corner tl/tr/bl/br"></div>
  <div class="readout tl/tr/bl/br"></div>  <!-- 四角文字读数 -->
  ...
```

**这印证了我们的 effects 方向是对的**（grid / scan / vignette / corners 我们都有），
差别是它的四角 readout 是**内容**（含实时时钟、RSRP/SINR/BLER、FPS、47 个节点网格），不是装饰。

> 可借鉴：加一个 `readout` 效果——四角显示"实时"数据（时钟、帧率、随机指标），成本低、氛围强。

## 身份卡（preview/ueg.html，85KB 独立页）

- 结构：seal 徽章图片 + **canvas 画的旋转地球** + 锁定准星 + 若干 readout
- 是**独立页面**，不依赖启动动画；说明它把"身份卡"当一个可单独演示的模块
- 地球用 canvas（我们用的是 SVG 正射投影，视觉更干净，但 canvas 更省 DOM）

## 对我们的结论

| 项 | 结论 |
| --- | --- |
| 编排模型 | 我们的时间线更适合用户改，不换 |
| 取消机制 | **要补**：把所有 setTimeout 接进取消体系 |
| simple/full 两级 | 可加，作为模板可选项 |
| 四角 readout | 值得做，作为新效果 `readout` |
| 身份卡 | 应做成**独立模块/图层**，不要塞在 steps 里 |
