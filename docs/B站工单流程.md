# B站用户提问：低上下文工单流程

> 目标：你只发「短工单」，我只回「可直接粘贴的答案」，不翻仓库、不展开解释，尽量少烧上下文。

## 一、三档方案（按场景选）

| 档位 | 做法 | 上下文成本 | 适合 |
|---|---|---|---|
| A 标签速答 | 消息以 `【B站工单】` 开头，按模板填 4 行 | 最低 | 90% 的提问 |
| B 文件工单 | 问题写进 `B站工单/待处理/日期-用户.md`，你只说“处理工单” | 低（我只读一个文件） | 一次多条、要留档 |
| C 子代理 | 你说“用子代理处理这条工单” | 最低（我只收结果） | 复杂问题、要查仓库 |

## 二、A 档模板（复制即用）

```text
【B站工单·速答】
版本：v2.8.3 / v2.5.2 / 不知道
系统：Win10 / Win11
现象：（一句话，原话粘贴，别改写）
附件：（截图/报错，没有就写无）
要求：只给可直接粘贴的回复，≤300 字，不动代码
```

### 我的处理规则（你发这个标签时，我默认做）

1. 不读仓库、不跑命令、不改文件（除非你写 `需要查仓库`）
2. 只输出一个「复制块」：用户能直接粘贴的中文回复
3. 不写分析过程、不写“我建议”、不追加问题
4. 答案里必须包含：先做什么 → 再做什么 → 还不行发什么

## 三、B 档：文件工单

目录：

```
B站工单/
├─ 待处理/2026-10-24-装完黑屏.md
└─ 已处理/（处理完我把回复写这里）
```

每个文件格式：

```text
版本：
系统：
现象：
附件：
```

你只需说：`处理 B站工单 待处理 目录`。我读文件、写回复、把文件移到 已处理。

## 四、C 档：子代理（最省上下文）

你说：`用子代理处理这条工单：<粘贴问卷>`。
我起一个独立子代理，把问题和安装文档丢给它，它只回我一段答案，我再转给你。
好处：中间查资料、试命令的过程不进主对话。

## 五、提问前先筛（能省一半工单）

按这个顺序让用户自查，约 70% 能自己解决：

1. 有没有**完全退出** DSH（窗口 + 托盘）再装？
2. 是不是用了 **v2.5.2 旧包**？（新版 v2.8.3 才适配新 DSH）
3. 有没有装过旧插件 / 另一个 profile？
4. 有没有 `诊断.cmd` 的报告？

## 六、示例

你发：

```
【B站工单·速答】
版本：不知道
系统：Win11
现象：装完打开只有黑屏一闪，没有动画
附件：无
要求：只给可直接粘贴的回复，≤300 字，不动代码
```

我回（只有这一块，没别的）：

```text
先确认三件事：1) 是否用 v2.8.3 安装包；2) 装之前有没有完全退出 DSH（托盘也退）；3) 是否装过旧版。
如果都确认了还黑屏：运行安装目录里的 诊断.cmd，把桌面生成的 dsh诊断-*.txt 发我。
临时恢复：运行 卸载.cmd，重开客户端就是没有动画的干净界面。
```
