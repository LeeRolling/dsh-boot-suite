## 2. 最小接入步骤

1. 把整个 `division-bigfish-codex/` 目录拷进插件资源目录（相对路径必需保持）。
2. 启动画面用 iframe 加载 **`index.html`**：

```html
<iframe src="division-bigfish-codex/index.html"
        style="width:100%;height:100%;border:0;background:#000"
        allow="autoplay; fullscreen"></iframe>
```

3. 监听完成事件（见 §4），收到后关闭启动画面、进入 DSH 主界面。
4. 如需改用户名/标题/文案，按 §3 改 `config.js`（或在加载前注入 `window.CONFIG`，见 §3.2）。

> 注意：`index.html` 引用的 `app.js`、`assets/*` 都是相对路径，**不能只拷 index.html**。

## 3. 参数

### 3.1 `config.js` 字段（全部可选，保持结构即可）

```js
window.CONFIG = {
  username: '人类与AI的日常',      // 「连接中：xxx」；必改
  title: '什么是「模板」？',        // 提示条标题
  description: '模板是别人做好的启动动画…', // 提示条正文
  duration: 25.92,                 // 源时间长度（成片会压到 20.33s）
  startAt: 3.4,                    // 跳过片头黑场前的起点，非必要不改
  loadingStart: 9.2,               // 连接态→加载态切换点（源时间）
  speedStart: 9.2, speed: 1.5, speedEnd: 25.45, // 加载段 1.5 倍速压缩
  voiceY: 908, voiceWidth: 520,    // DSH 行位置与宽度
  egg: { at: 9.2 },                // 彩蛋判定点（源时间=加载段开始）
  voice: {
    orig1: 'assets/voice-orig1.wav', line1: '…', line2: '…',
    line3: '…', orig3: '…', line4: '…',
    sched: [[4.6,'orig1',2.65],[8.0,'line1',3.375],[12.8,'line2',3.232],[17.9,'line3',3.300],[25.45,'orig3',2.77]],
    eggLineAt: 1.0,      // 掉线画面出现后 1s 播 line4
    line4Dur: 1.911,
    eggReplayWait: 2.0   // line4 说完后等 2s 自动重播
  },
  progress: [[9.2,0],[10,0],[10.9,0],…,[25.45,100],[25.92,100]]
};
```

- `username` 是必改项；其余文案/时长不改也能用。
- 改时长/语音时，`voice.sched` 与 `progress` 里的时间点要一起调（都是**源时间**，不是成片时间）。

### 3.2 动态注入（宿主传参）

模板本身**不监听** `postMessage` 配置（当前实现），有二选一方案：

1. **服务端替换**：插件把 `config.js` 作为模板生成，写入宿主拿到的 username 等；
2. **前置脚本**：iframe 指向插件自己的 `boot.html`，内容为：

```html
<script>window.CONFIG = { /* 宿主参数 */ };</script>
<script src="division-bigfish-codex/config.js"></script>
<iframe src="division-bigfish-codex/index.html" …></iframe>
```

> 注意：`config.js` 会覆盖此前设置的 `window.CONFIG`，若用方案 2 要把参数合并后再加载 `index.html`，或直接改 `config.js` 文本（最稳）。如希望模板原生支持 `postMessage` 配置，可在插件上下文里加约 10 行监听，我可以补。

## 4. 事件与运行控制

宿主监听以下任意一条即可（三条通道同时触发）：

### 4.1 跳过

| 通道 | 形式 |
|---|---|
| DOM | `document.addEventListener('dsh-startup-skip', fn)` |
| postMessage | `{ type: 'dsh-startup-skip' }`（来自 iframe） |
| 全局函数 | `window.__DSH_SKIP__()`（同 window 内可用） |

### 4.2 完成（进入 DSH 主界面）

| 通道 | 形式 |
|---|---|
| DOM | `document.addEventListener('dsh-startup-done', fn)` |
| postMessage | `{ type: 'dsh-startup-done' }` |
| 全局函数 | `window.__DSH_DONE__()` |

- 正常版：100% 后约 3.7s（含第五句播完 + 白闪）触发。
- 彩蛋版：点「重新连接」→ 重播 0–100% → 白闪后触发。
- 宿主收到后关闭启动层即可；**不要再等固定时长**（彩蛋会拉长总时长）。

### 4.3 运行控制（可选）

```js
window.__DSH_APP__ = { play, pause, seek, showEgg, eggFrame, flashDone };
```

- `pause()`/`play()`：宿主切后台/失焦时暂停动画与音频。
- `seek(秒)`：仅调试用。
- `showEgg()` / `eggFrame(秒)` / `flashDone()`：调试试看彩蛋和结尾，不建议生产使用。

## 5. 彩蛋规则（务必保留）

- 概率：`app.js` 内 `EGG_CHANCE = 0.28`（写死；要可配置需改一行）。
- 判定：**每次启动只判定一次**，判定点 = 加载段开始（`egg.at`，源时间 9.2s）。
- 触发：**硬切**到掉线画面 → 静 1s → line4（1.911s）→ 静 2s → 自动重播进度条；用户点「重新连接」则**立即**重播。
- 掉线画面：黑纱 + 《战术大肥鱼®》错误框 + `DELTA / C-0-1302` + 「重新连接」+ 底部 DSH。
- 调试参数：`?egg=1` 强制触发；`?mute=1` 静音；`?play` 自动播放（render.html 用，index 默认自动）。
- **演示视频里的掉线点固定在 5.8s 只是为便于逐帧核对**，真实页面是随机的（0.28）。

## 6. 时间轴（成片时间，30fps）

正常版（20.3337s = 610 帧）：

| 段 | 时间 | 内容 |
|---|---|---|
| 连接态 | 0.000–5.800 | 圆环 + 「连接中：username」+ orig1（1.2s 起） |
| 加载态（1.5×） | 5.800–16.633 | 提示条 + 百分比 + line1（4.6）/line2（8.2）/line3（11.6） |
| 100% 静止 | 16.633–19.933 | orig3（16.633 起，2.77s），DSH 随语音显示 |
| 白闪 | 19.933–20.283 | 闪白 0.35s → done |

彩蛋演示（25.2333s）：连接 0–5.8 → 掉线画面 5.8–10.733（1s 静默 + line4 1.911 + 2s 静默）→ 重播 0–100% 10.733–21.566 → 100% 静止 → 白闪 → done。

## 7. 验收清单（接入后自测）

- [ ] iframe 加载后首帧纯黑，无旧画面闪帧。
- [ ] 1920×1080 下文字/圆环无裁切；缩放容器时保持 16:9 居中。
- [ ] 第一句「Alert. New agent login detected.」、第五句「welcome back Agent…」在音轨里可听（orig1/orig3）。
- [ ] DSH 波形与语音同进同出（100% 前不提前出，说完不残留）。
- [ ] 右上「跳过 ▸」可点，触发 skip 事件并关闭。
- [ ] 正常结束触发 done（约 20.3s；不要写死 25.9s）。
- [ ] 彩蛋（可 `?egg=1` 强制）：硬切、1s 静 → line4 → 2s 静 → 自动重播；点「重新连接」立即重播；重播后 done。
- [ ] 彩蛋画面里没有残留波形/跳过按钮。
- [ ] 音频可播（iframe `allow="autoplay"` 或首次点击）。

## 8. 已知边界（不是 bug）

- 无 BGM；音频需用户交互后才可能出声（浏览器策略）。
- 演示视频的掉线点固定，真实页面随机 0.28。
- 模板未实现宿主→iframe 的 postMessage 配置通道（见 §3.2）。
- 历史版本：根目录还留有 v8–v12 成片与 `frames*` 缓存；**接插件只需 `templates/division-bigfish-codex/` 这一份**。
